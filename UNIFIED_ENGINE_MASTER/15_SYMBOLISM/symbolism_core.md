# Модуль символики и сквозных образов

**Что это:** Реестр символов, образов и мотивов которые проходят через всю серию.
**Зачем:** Серия ощущается цельной когда образы возвращаются с новым смыслом. GPT не отслеживает это между главами — отслеживаешь ты через этот реестр.

---

## ЧТО ТАКОЕ РАБОЧИЙ СИМВОЛ

Символ в коммерческой прозе — это не литературоведение. Это деталь которая:
1. Появляется более одного раза
2. Каждый раз несёт немного другой смысл
3. В финале арки или серии — полный смысл

Пример механики:
- Гл.1: персонаж носит отцовский нож. Деталь характера.
- Гл.7: нож ломается в бою. Потеря защиты.
- Гл.14: персонаж выбрасывает обломок. Отпускает прошлое.
- Гл.20: персонаж дарит новый нож кому-то другому. Передаёт то что получил.

Читатель не обязан это анализировать. Он чувствует — и это работает.

---

## ЧТО РАБОТАЕТ КАК СИМВОЛ

**Предметы:** оружие, одежда, украшение, книга, письмо — что-то физическое что можно держать.
**Места:** конкретное место с историей — возвращение в него меняет значение.
**Фраза или слово:** то что один персонаж говорит другому — и это возвращается.
**Действие:** ритуальное — делается одинаково, но контекст меняет смысл.
**Физическое состояние:** шрам, рана, отсутствие чего-то.

## РЕЕСТР СИМВОЛОВ — ШАБЛОН

```
# Реестр символов: [название серии]

## Символ: [название/описание]
Тип: [предмет / место / фраза / действие / состояние]
Введён: Гл.[N], сцена [краткое описание]
Начальное значение: [что означает при первом появлении]

Появления:
- Гл.[N]: [контекст] → значение: [как изменилось]
- Гл.[N]: [контекст] → значение: [как изменилось]

Запланированные появления:
- Гл.[N] примерно: [как должен появиться и что должен означать]
- Финал арки: [финальное значение]

Связанные персонажи: [кто с ним связан]
```

## ПРОМПТ ДЛЯ СОЗДАНИЯ РЕЕСТРА — подай в Claude

```
Помоги создать систему символов для фэнтези серии.

ЖАНР: [эпическое / городское / тёмное фэнтези]
ЦЕНТРАЛЬНАЯ ТЕМА СЕРИИ: [одно предложение]
ГЛАВНЫЕ ПЕРСОНАЖИ: [список с кратким описанием]
КЛЮЧЕВЫЕ КОНФЛИКТЫ: [внешний и внутренний]

Предложи:
1. 3-4 символа которые могут работать через всю серию
   Для каждого: начальное значение, как может эволюционировать, финальное значение
2. 2-3 сквозные фразы которые могут возвращаться с новым смыслом
3. 1-2 места которые стоит использовать как символические точки

Не придумывай абстрактных символов — только то что можно показать конкретно.
```

## КАК НЕ ИСПОРТИТЬ

**Не объясняй символ.** Если персонаж думает "этот нож напоминает мне об отце и о том как я вырос" — символ мёртв.

**Не каждая деталь символ.** Реестр из 20 символов = нет символов, есть хаос.
3-5 на серию максимум.

**Символ не обязан быть очевидным.** Читатель не должен думать "о, это символизирует X". Он должен чувствовать вес момента.

**Возвращение не должно быть объявлено.** "Он снова взял в руки отцовский нож — как тогда, в начале" — плохо.
Просто показывай деталь. Читатель вспомнит сам.
