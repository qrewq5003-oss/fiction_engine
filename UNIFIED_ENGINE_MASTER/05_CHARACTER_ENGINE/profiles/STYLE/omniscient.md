# Стилевой профиль: Omniscient

Суть: Нарратор знает всё — включая мысли всех персонажей.
Риск: читатель теряет идентификацию с одним персонажем.
Сила: возможность показать иронию и контраст между тем что думают разные люди.

## ПРИЁМЫ

В каждой сцене мысли минимум двух персонажей: рассказчик переходит из головы в голову внутри сцены.
Раз на сцену рассказчик сообщает то, чего не знает ни один герой: «Он не знал, что…».
Ирония контраста: рядом мысли двоих об одном и том же, и они расходятся.
Рассказчик обобщает о людях, городе, времени — одной фразой, без морали.
Только третье лицо: у рассказчика нет «я».

Подходит для: эпик, семейная сага, исторический роман.
