# Библиотека голосов

Три части:
1. `voice_profiles/` — стилевые эталоны для разных типов фэнтези
2. `voice_builder.md` — инструмент для создания профиля своего голоса
3. `voice_check.md` — быстрая проверка что голос не потерян

Эталоны написаны как образцы — не копировать, использовать для настройки GPT.
