# Быстрая проверка голоса

**Когда:** После генерации любой главы. Занимает 2 минуты.

---

## САМОПРОВЕРКА (без Claude)

Прочитай первый абзац новой главы и первый абзац предыдущей.

Спроси себя:
- Длина предложений похожа?
- Тот же способ описания деталей?
- Диалог атрибутирован так же?
- Узнаётся ли голос с первых строк?

Если "нет" хотя бы на два вопроса — проверяй через Claude.

---

## ПРОВЕРКА ЧЕРЕЗ CLAUDE (2 минуты)

```
Сравни два отрывка. Один вопрос: это один автор?
Если нет — что конкретно изменилось (максимум 3 пункта).

ОРИГИНАЛ:
[3-4 предложения из предыдущей главы]

НОВЫЙ:
[3-4 предложения того же типа из новой главы]
```

---

## ЧТО ДЕЛАТЬ С РЕЗУЛЬТАТОМ

**Потеряна длина предложений:**
Добавь в промпт: "Предложения в экшн-сценах: 5-8 слов. Не длиннее."

**Потерян способ передачи эмоций:**
Добавь в промпт: "Эмоции только через [физику тела / действие / иронию]. Не называть напрямую."

**Потерян стиль диалога:**
Добавь в промпт: "Атрибуция только 'сказал/спросил'. Никаких 'произнёс задумчиво', 'ответил с горечью'."

**Появились ИИ-клише:**
Добавь конкретные примеры из ai_cliches.md в промпт как явные запреты.

---

## ПРАВИЛО

Лучше потратить 2 минуты на проверку сейчас чем переписывать главу потом.
Голос проще удержать чем восстановить.
