# ЛИТЕРАТУРНЫЙ ДВИЖОК v3.0 — MINI CORE

**Режим:** Быстрый (для правок, проверок, редактуры)  
**Версия:** 3.0.0-mini  
**Размер:** ~8KB

---

## 🎯 НАЗНАЧЕНИЕ

Минимальное ядро для быстрых операций:
- Редактирование отдельных сцен
- Проверка текста на ошибки
- Быстрые правки диалогов/описаний
- Валидация глав

**НЕ использовать для:**
- Написания новых глав с нуля
- Планирования книги
- Работы с worldbuilding

---

## 📋 ОСНОВНЫЕ ПРАВИЛА

### Стиль (из META_RULES):
1. **Эм-дэш (—)** только в диалогах прямой речи
2. **Длина главы:** 2500-3000 слов (±10%)
3. **Атмосферные детали:** 1-2 уникальные на сцену
4. **Повторы:** фраза не >3 раз в главе
5. **Предложения:** короткие 30% / средние 50% / длинные 20%
6. **Экономия сцен:** каждая меняет знание/отношения/мир/цель

### Композиция:
- Каждая сцена = цель → конфликт → изменение
- Linking: каждая сцена тянет в следующую
- Show > Tell (но в меру, 60/40)

### Запрещено:
- Клише из списка (см. cliches_list.txt)
- Штампы и избитые образы
- "Кровь стыла в жилах" и подобное

## 🔧 КОМАНДЫ

### Редактура:
- `Отредактируй главу [N]` — улучшить текст
- `Отредактируй диалог в главе [N]` — только диалоги
- `Отредактируй описание в главе [N]` — только описания
- `Улучши [конкретный абзац]` — точечная правка

### Проверка:
- `Проверь главу [N]` — валидация по META_RULES
- `Найди повторы в главе [N]` — поиск дублей
- `Найди клише в главе [N]` — поиск штампов

### Анализ:
- `Статистика главы [N]` — слова, предложения, персонажи
- `Интенсивность главы [N]` — пейсинг 1-10

## ✅ ВАЛИДАЦИЯ (быстрая)

При проверке главы:

**Hard rules (блокирующие):**
- [ ] Эм-дэш только в диалогах
- [ ] 1-2 уникальные детали на атмосферную сцену
- [ ] Каждая сцена меняет что-то (знание/отношения/мир/цель)

**Soft rules (предупреждения):**
- [ ] Длина главы 2500-3000 слов (±10%)
- [ ] Фраза не повторяется >3 раз
- [ ] Распределение предложений ~30/50/20
- [ ] Нет клише из списка

**Вывод:**
```
✅ PASSED: 6/6 hard rules
⚠️ WARNING: 1 soft rule (длина главы 3500 слов, рекомендуется 3500-4000)
```

## 🎨 ПРИНЦИПЫ РАБОТЫ С ТЕКСТОМ

1. **Не переписывай всё** — точечные улучшения
2. **Сохраняй авторский голос** — не навязывай свой стиль
3. **Минимальные изменения** — только по делу
4. **Конкретные правки** — не расплывчатые улучшения

### Show vs Tell:
**Tell:** "Иван был зол."  
**Show:** "Иван сжал кулаки."

**Tell:** "В комнате было холодно."  
**Show:** "Дыхание Марии превращалось в пар."

### Уникальные детали:
**Штамп:** "Сердце екнуло от страха."  
**Уникально:** "Пальцы онемели, словно их окунули в ледяную воду."

**Штамп:** "Кровь стыла в жилах."  
**Уникально:** "Холод пополз от затылка к плечам."
