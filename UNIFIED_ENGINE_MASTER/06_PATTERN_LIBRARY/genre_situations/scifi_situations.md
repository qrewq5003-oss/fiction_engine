# Паттерны: НФ ситуации

---

## СИТУАЦИЯ 1: Введение допущения через персонажа

**Задача:** Читатель понимает как работает мир — через жизнь персонажа, не через объяснение.
**Напряжение:** Информация подаётся как обычная жизнь — не лекция.

ТЕХНИКА:
Персонаж делает что-то обыденное для его мира — необычное для читателя.
Не объясняй — показывай реакцию на это как на обычное.
Детали которые создают вопрос — ответ придёт позже через действие.

СТРУКТУРА:
— Обычный день персонажа с необычными деталями
— Одна деталь которая требует понимания — показана без объяснения
— Ситуация которая вынуждает объяснение — коротко, в контексте
— Немедленное применение этого знания

ОШИБКИ:
- "Как ты знаешь, в нашем мире с 2045 года..."
- Персонаж объясняет очевидное другому персонажу который должен это знать
- Инфодамп в первой главе

## СИТУАЦИЯ 2: Этическая дилемма технологии

**Задача:** Технология создаёт выбор между двумя правильными или двумя неправильными вариантами.
**Напряжение:** Нет очевидного ответа.

ТЕХНИКА:
Оба варианта имеют реальные обоснования.
Персонаж с каждым вариантом ассоциирован реальный человек — не абстракция.
Решение вытекает из характера персонажа — и показывает кто он.

СТРУКТУРА:
— Ситуация где нужно решить
— Аргументы за первый вариант — конкретные лица
— Аргументы за второй — конкретные лица
— Решение через характер
— Первое последствие — не финальное

ОШИБКИ:
- Один вариант явно правильный
- Последствия не показаны
- Решение без внутреннего конфликта

---

## СИТУАЦИЯ 3: Контакт с иным (существо, система, цивилизация)

**Задача:** Встреча с тем что мыслит иначе — и это не просто другой человек.
**Напряжение:** Непонимание может быть опасным — с обеих сторон.

ТЕХНИКА:
Иное должно быть реально иным — не человек в костюме.
Коммуникация затруднена — и это само по себе сюжет.
Персонаж проецирует человеческие паттерны — и ошибается.

СТРУКТУРА:
— Первый контакт — непонимание
— Попытка найти общий язык — частичный успех
— Критическое недопонимание — с последствием
— Момент реального контакта — через что-то неожиданное
— Что это меняет

ОШИБКИ:
- Иное мгновенно понимает человеческий язык и логику
- Иное просто злое без причины
- Контакт решается легко
