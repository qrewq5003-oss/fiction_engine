# Промпт: Обновление State Engine после главы

**Когда:** Сразу после финализации каждой главы. Занимает 2-3 минуты.  
**Подавать в:** Claude

---

## ПРОМПТ

```
Прочитай эту главу и обнови State Engine. Верни только изменения — не пересказывай то что не изменилось.

ТЕКУЩИЙ STATE (вставь актуальные файлы):
[global_state.md]
[plot_matrix.md]  
[memory_graph.md]

НОВАЯ ГЛАВА:
[вставь текст главы]

Верни в формате:

=== GLOBAL_STATE — ИЗМЕНЕНИЯ ===
Персонаж [Имя]:
  состояние: [было → стало]
  локация: [если изменилась]
  цель: [если изменилась]
  ключевые изменения: [что произошло с этим персонажем]

Мир:
  [что изменилось в мире, фракциях, ситуации]

=== PLOT_MATRIX — ИЗМЕНЕНИЯ ===
Линия [название]:
  статус: [было → стало]
  что произошло: [одно предложение]
  следующий шаг: [что логично дальше]

Новые линии открытые в этой главе:
  [если есть]

Линии закрытые в этой главе:
  [если есть]

=== MEMORY_GRAPH — ИЗМЕНЕНИЯ ===
[Имя] теперь знает:
  - [факт]: источник [кто сказал / что увидел]

[Имя] теперь НЕ знает (узнал что предыдущая информация была ложной):
  - [факт]

Новые секреты (кто знает что, и кто не знает):
  [если есть]

=== КЛИФФХЭНГЕРЫ И ОТКРЫТЫЕ ВОПРОСЫ ===
[список вопросов которые глава открыла и не закрыла — для следующих глав]
```

---

## КАК ПРИМЕНЯТЬ РЕЗУЛЬТАТ

1. Открой три файла State Engine
2. Внеси только изменения из ответа Claude — не переписывай весь файл
3. Добавь номер главы рядом с каждым изменением: `[Гл.12]`
4. Сохрани

Формат в файлах:
```
## Персонаж: Кира
Состояние: ранена, скрывается [Гл.12]
Локация: заброшенная таверна на востоке [Гл.12]
Знает: Наставник предал орден [Гл.11], артефакт у Серого [Гл.12]
Не знает: настоящая цель Серого, кто заказчик
Цель: найти артефакт до рассвета [Гл.12]
```

---

## ПОЧЕМУ ВАЖНО ДЕЛАТЬ СРАЗУ

Если пропустить обновление после главы и вернуться через 3-5 глав — придётся восстанавливать по памяти или перечитывать. Это занимает в 10 раз больше времени чем обновление сразу.

State Engine — не документация. Это активный контекст для следующей генерации.
