# GLOBAL STATE ENGINE

**Модуль:** 06_STATE_ENGINE/global_state.md  
**Назначение:** Отслеживание состояния мира и персонажей для длинных серий (100+ глав)

---

## 🎯 НАЗНАЧЕНИЕ

Global State Engine отслеживает:
- Состояние всех персонажей (локация, статус, отношения)
- События и их последствия
- Временную линию
- Изменения в мире
- Активные сюжетные линии

**Для чего:** Избежать противоречий в длинных сериях (когда персонаж был в Москве в главе 50, а в главе 100 "впервые приезжает в Москву").

---

## 📋 СТРУКТУРА СОСТОЯНИЯ

## 🔧 ИСПОЛЬЗОВАНИЕ

### При написании главы N:

**ШАГ 1: Загрузить состояние**
```
Загрузить Global State на главу N-1
```

**ШАГ 2: Проверить continuity**
- Где был персонаж X в последний раз?
- Что он знает на данный момент?
- Какие события влияют на текущую главу?
- Какие сюжетные линии активны?

**ШАГ 3: Написать главу**
С учётом всего состояния

**ШАГ 4: Обновить состояние**
- Изменения персонажей (локация, знания, отношения)
- Новые события
- Прогресс сюжетных линий
- Изменения в мире

## 📊 ПРОВЕРКИ CONTINUITY

### Автоматические проверки:

**1. Противоречия локаций:**
```
Глава 127: Ковалёв в Москве
Глава 128: Ковалёв в Петербурге
Проверка: Как добрался? Сколько времени прошло?
```

**2. Противоречия знаний:**
```
Глава 125: Ковалёв узнаёт имя убийцы
Глава 130: Ковалёв говорит "мы не знаем, кто это"
⚠️ ОШИБКА: Персонаж забыл, что знал
```

**3. Противоречия отношений:**
```
Глава 100: Ковалёв и Анна поссорились
Глава 101: Ковалёв и Анна держатся за руки
⚠️ ОШИБКА: Нужна сцена примирения между 100-101
```

**4. Мёртвые персонажи:**
```
Глава 120: Напарник погиб
Глава 135: Напарник говорит с Ковалёвым
⚠️ КРИТИЧЕСКАЯ ОШИБКА
```


- Ковалёв: теперь в офисе мэра (не в своём офисе)

## 🔥 КРИТИЧЕСКИЕ ПРАВИЛА

1. **Обновляй состояние ПОСЛЕ КАЖДОЙ ГЛАВЫ**
   - Персонажи меняют локацию
   - Получают новые знания
   - Меняются отношения

2. **Проверяй continuity ПЕРЕД написанием**
   - Где был персонаж?
   - Что он знает?
   - Какие события произошли?

3. **Отслеживай время**
   - Сколько дней прошло?
   - Логично ли перемещение?
   - Успел ли персонаж добраться?

4. **Не воскрешай мёртвых**
   - Мёртвые остаются мёртвыми
   - Исключение: флешбэки (отметь!)

5. **Связывай события**
   - Каждое событие имеет последствия
   - Отслеживай причинно-следственные цепочки
