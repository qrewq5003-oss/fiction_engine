# Архив

Файлы, которые Fiction Engine не читает и которые описывают то, что в
приложении устроено иначе или уже есть в рабочих файлах базы. Пути внутри
архива повторяют прежние, чтобы старые ссылки было легко найти.

| Что | Почему в архиве |
| --- | --- |
| `07_SYSTEM_ENGINE/` | Проектные заметки о «контроллере», «обучении на данных», «валидаторе памяти» и голосе автора. Реализованное живёт в коде приложения и устроено иначе |
| `08_STATE_ENGINE/` | Состояние мира в markdown-файлах для ручной работы. В приложении State Engine хранится в SQLite |
| `04_GENRE_ENGINE/AUTO_ROUTER.md` | Таблица маршрутизации для ручного выбора модулей. В приложении — `engine/auto_router.py` |
| `00_CORE/CORE_FULL.md`, `CORE_MINI.md`, `style_rules.md`, `cliches_list.txt` | Ядро для ручной вставки в чат. Содержание есть в `00_CORE/ai_cliches.md`, `00_CORE/META_RULES.yaml` и секциях PROMPT модулей |
| `IMPROVEMENTS_CRITIQUE.md` | Историческая записка о переходе v3 → v4 |

Перенесено в v2.0 (2026), см. `AUDIT_UNIFIED.md` в корне репозитория.
