# Чеклист валидации: Фэнтези

---

## МИР И МАГИЯ

[ ] Правила магии последовательны с предыдущими главами
[ ] Магия имеет цену — физическую, эмоциональную или моральную
[ ] Новая информация о мире подаётся через ситуацию — не монолог
[ ] Мир показан через то как персонажи в нём живут

## ПЕРСОНАЖ И ДУГА

[ ] Протагонист меняется — не только становится сильнее
[ ] Каждая победа стоит чего-то личного
[ ] Выборы вытекают из характера — не из сюжетной необходимости
[ ] Наставник или союзник имеет собственные цели

## АНТАГОНИСТ

[ ] Мотивация понятна и логична в рамках его мировоззрения
[ ] Является реальной угрозой — не некомпетентен
[ ] Зеркалит протагониста — или мог бы им быть при других выборах

## СТРУКТУРА ГЛАВЫ

[ ] Есть внешнее и внутреннее действие
[ ] Моральная сложность присутствует — нет чёрного/белого
[ ] Финал главы меняет что-то — знание, ситуацию, отношения

## КРАСНЫЕ ФЛАГИ

[ ] Новая сила появляется именно когда нужна без подготовки
[ ] Экспозиция через монолог или "как ты знаешь, Гермиона..."
[ ] Все союзники преданы, все враги злы без причины
[ ] Магия решает проблему без цены
[ ] Победа без потерь в кульминации
