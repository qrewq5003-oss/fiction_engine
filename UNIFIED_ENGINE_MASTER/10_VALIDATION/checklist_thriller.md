# Чеклист валидации: Триллер

---

## НАПРЯЖЕНИЕ И ТЕМП

[ ] Напряжение нарастает — не статично
[ ] Каждое решение протагониста сужает варианты или создаёт новую проблему
[ ] Дедлайн присутствует и ощущается через действия
[ ] Короткие предложения в экшн-сценах, длиннее в паузах
[ ] Ложная безопасность присутствует — и нарушается

## ПРОТАГОНИСТ

[ ] Активно действует — не реагирует пассивно
[ ] Принимает решения исходя из характера
[ ] Ошибается под давлением — это правдоподобно
[ ] Паранойя оправдана — угроза реальна

## АНТАГОНИСТ

[ ] Компетентен и имеет ресурсы
[ ] Его действия логичны
[ ] Не некомпетентен именно в финале

## ИНФОРМАЦИЯ

[ ] Читатель знает не больше протагониста (или чуть больше — для тревоги)
[ ] Предательство/двойная игра подготовлены ранними деталями
[ ] Информация раскрывается порционно — нет инфодампа

## КРАСНЫЕ ФЛАГИ

[ ] Герой спасается случайно
[ ] Союзник предаёт без подготовки
[ ] Антагонист объясняет план монологом
[ ] Темп провисает посередине
[ ] Финальная победа без цены
