# Чеклист валидации: Научная фантастика

---

## МИР И ДОПУЩЕНИЕ

[ ] Научное или технологическое допущение последовательно с предыдущими главами
[ ] Правила мира не нарушаются ради сюжетной удобности
[ ] Технология показана через то как люди с ней живут — не через энциклопедический монолог
[ ] Инопланетяне, ИИ, чужие культуры думают иначе чем современные люди

## ПЕРСОНАЖ В СИСТЕМЕ

[ ] Персонаж адаптирован к своему миру — не удивляется обыденному
[ ] Идея воплощена в конкретной судьбе конкретного человека
[ ] Большая тема (власть, технология, общество) читается через личный выбор
[ ] Протагонист платит реальную цену за свои действия в рамках системы

## ЭКСПОЗИЦИЯ МИРА

[ ] Мир объясняется через действие и диалог — персонажи не объясняют друг другу привычное
[ ] Новый элемент мира вводится когда он нужен сюжету — не авансом
[ ] Сенсорные детали специфичны для этого мира (запах, звук, текстура)
[ ] Технический язык органичен — не глоссарий в тексте

## КОНФЛИКТ И ФИНАЛ

[ ] Конфликт связан с допущением — не мог бы произойти в обычном мире
[ ] Победа или поражение имеют последствия в рамках системы мира
[ ] Финал не даёт дидактической морали — читатель делает выводы сам
[ ] Если есть идея — она спорна, не декларируется как истина
