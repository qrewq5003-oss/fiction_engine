# Чеклист валидации: Романтика

---

## ХИМИЯ И ОТНОШЕНИЯ

[ ] Химия показана через конкретные детали и поведение — не объявлена
[ ] Оба персонажа замечают друг друга — оба сопротивляются
[ ] Любовный интерес имеет собственную жизнь, цели, проблемы
[ ] Притяжение вытекает из характеров — не только из внешности

## КОНФЛИКТ

[ ] Внутренний барьер у протагониста конкретен и реален
[ ] Конфликт не решается простым разговором
[ ] Оба персонажа несут ответственность за напряжение — не один виноват
[ ] Чёрный момент убедителен — читатель верит что конец

## ПЕРСОНАЖИ

[ ] Протагонист симпатичен несмотря на недостатки
[ ] Любовный интерес не существует только ради протагониста
[ ] Оба меняются к финалу — не только один
[ ] Голоса различимы если dual POV

## ТЕМП

[ ] Эмоциональные пики чередуются с тихими сценами
[ ] Нарастание напряжения между персонажами последовательно
[ ] Нет резкого ускорения в финале без подготовки

## КРАСНЫЕ ФЛАГИ

[ ] Miscommunication как единственный конфликт
[ ] Токсичное поведение подано как романтичное
[ ] Любовный интерес — приз а не человек
[ ] HEA слишком лёгкое — без реального изменения
[ ] Химии нет — они просто говорят что влюблены
