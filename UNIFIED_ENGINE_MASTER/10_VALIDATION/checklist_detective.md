# Чеклист валидации: Детектив

Проверяй каждую главу перед финализацией.

---

## СТРУКТУРА И СЮЖЕТ

[ ] Глава двигает расследование — новая улика, новый подозреваемый, новое препятствие
[ ] Детектив активно действует — не ждёт пока информация сама придёт
[ ] Улики которые даны читателю — честные (можно вычислить)
[ ] Ложные следы присутствуют и убедительны
[ ] Темп не провисает — нет сцен без функции

## ДЕТЕКТИВ КАК ПЕРСОНАЖ

[ ] Метод детектива последователен с предыдущими главами
[ ] Детектив делает ошибку или ложный вывод хотя бы раз
[ ] Его наблюдения показаны через действие ("заметил X") а не задекларированы ("он был наблюдателен")
[ ] Голос детектива в монологе/диалоге узнаваем и последователен

## ДИАЛОГ

[ ] Подозреваемые/свидетели скрывают или искажают — не говорят прямо
[ ] Диалог несёт подтекст — не только информацию
[ ] Атрибуция минимальна — "сказал" без эмоциональных ремарок там где они не нужны
[ ] Реплики различимы по характеру — разные персонажи говорят по-разному

## АТМОСФЕРА

[ ] Место действия создаёт настроение через 1-2 конкретные детали
[ ] Сенсорные детали конкретны (не "было темно" а что именно)
[ ] Атмосфера соответствует субжанру (нуар — мрачно, cozy — уютно)

## АНТАГОНИСТ

[ ] Антагонист присутствует или его влияние ощущается
[ ] Его действия логичны с его точки зрения
[ ] Не даёт слишком много информации о себе

## КРАСНЫЕ ФЛАГИ

[ ] Детектив знает ответ слишком рано
[ ] Свидетель рассказывает всё сам без давления
[ ] Случайное совпадение решает проблему
[ ] Слишком подробное описание вместо действия
[ ] Детектив объясняет своё мышление вслух развёрнуто
