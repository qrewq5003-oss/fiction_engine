# Чеклист валидации: Универсальный

Применяется к любой главе в любом жанре. Дополняется жанровым чеклистом.

---

## СТРУКТУРА ГЛАВЫ

[ ] Глава начинается с действия или ситуации — не с описания
[ ] Первое предложение захватывает или удерживает
[ ] В главе есть поворот или сдвиг — что-то изменилось к концу
[ ] Последнее предложение несёт вес — клиффхэнгер или тихий удар
[ ] Главу нельзя убрать без потери для сюжета или характера

## ПЕРСОНАЖИ

[ ] Персонажи действуют исходя из характера — не из сюжетной необходимости
[ ] Разные персонажи говорят по-разному — голоса различимы
[ ] Эмоции показаны через поведение — не названы напрямую
[ ] Протагонист активен — принимает решения

## ДИАЛОГ

[ ] Каждая реплика несёт функцию — характер, информация, напряжение
[ ] Нет реплик только для заполнения
[ ] Подтекст присутствует — не всё сказано прямо
[ ] Атрибуция не перегружена эмоциональными ремарками

## ОПИСАНИЯ

[ ] Описания конкретны — не абстрактны
[ ] 1-2 детали на сцену — не инвентарь
[ ] Детали работают на настроение и характер
[ ] Нет клише из списка cliches_list.txt

## ТЕМП

[ ] Длина предложений соответствует темпу сцены
[ ] Нет провисаний — сцен без функции
[ ] Переходы между сценами чёткие

## КРАСНЫЕ ФЛАГИ — СТОП

[ ] Персонаж делает что-то только потому что сюжет требует
[ ] Проблема решается случайным совпадением
[ ] Новый персонаж/навык/информация появляется только когда нужна без подготовки
[ ] Монолог злодея объясняющий план
[ ] Эмоция названа напрямую вместо того чтобы быть показанной
[ ] Клише из списка
