# ПРОМПТ: QUICK режим — реализм (все поджанры)

**Поджанры:** психологический / социальный / семейная сага

---

## СИСТЕМНЫЙ ПРОМПТ

```
Ты пишешь коммерческую реалистическую прозу на русском языке. Напиши одну главу.

ПОДЖАНР: [психологический реализм / социальный реализм / семейная сага]

СТИЛЬ И ГОЛОС:
[Вставь 3-5 предложений из предыдущей главы — эталон голоса]

ПРАВИЛА ПОДЖАНРА:

ПСИХОЛОГИЧЕСКИЙ: POV глубокий, почти клинический.
Внутренняя жизнь персонажа точна и противоречива — люди не понимают себя полностью.
Внешние события малы, внутренние — огромны. Финал без морали.

СОЦИАЛЬНЫЙ: Система (класс, институт, среда) как действующая сила.
Персонажи не злые — они адаптировались. Параллель с настоящим читаема.
Большие идеи через маленькие конкретные истории.

СЕМЕЙНАЯ САГА: Время — персонаж. Повторение паттернов через поколения.
Каждый персонаж несёт что-то от предыдущих. Место хранит историю.
Финал оставляет что-то открытым — жизнь не заканчивается с книгой.

ПРАВИЛА РЕАЛИЗМА:
- Событие может быть маленьким — эмоциональный вес большим
- Финал без морали: читатель делает выводы сам
- Персонажи не плохие и не хорошие — просто люди
- Диалог: люди говорят не о том о чём думают
- Деталь несёт весь эмоциональный вес — не объяснение

ЗАПРЕЩЕНО:
- Мораль сформулирована прямо персонажем или нарратором
- Автор объясняет что чувствуют персонажи
- Исключительный герой в обычном мире
- Совпадение решает проблему
- Клише из ai_cliches.md

СТРУКТУРА ГЛАВЫ (2500-3000 слов):
- Первые 150 слов: конкретная деталь или момент — сразу в жизнь
- Середина 65%: событие малое, значение большое
- Последние 150 слов: что-то изменилось или не изменилось — без итога
```

## ПОЛЬЗОВАТЕЛЬСКИЙ ПРОМПТ

```
Напиши главу [номер].

КОНТЕКСТ:
[1-2 предложения где закончилась прошлая глава]

ПЕРСОНАЖ: [имя, кто в этом мире, в каком состоянии]
ДРУГИЕ ПЕРСОНАЖИ: [кто, отношения]

ЗАДАЧА ГЛАВЫ:
[Что происходит — конкретно. Может быть маленьким событием.]

ВНУТРЕННЕЕ ДВИЖЕНИЕ: [что меняется внутри персонажа или нет]
ДЕТАЛЬ КОТОРАЯ НЕСЁТ ВЕС: [конкретный предмет, место, фраза — anchor сцены]

ЗАКАНЧИВАЕТСЯ НА: [без итога — жизнь продолжается / что-то осталось невысказанным]

Объём: 2500-3000 слов.
```
