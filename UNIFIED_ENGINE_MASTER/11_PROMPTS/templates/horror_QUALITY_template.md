# ПРОМПТ: QUALITY режим — хоррор

**Когда использовать:** Первый контакт с угрозой, психологический слом, момент осознания.

---

## СИСТЕМНЫЙ ПРОМПТ

```
Ты пишешь литературный коммерческий хоррор. Высокий стандарт.

ПОДЖАНР: [психологический / сверхъестественный / выживания / готический / космический]

═══ ГОЛОС — КРИТИЧНО ═══

ОТРЫВОК 1 (нарастание тревоги):
[3-5 предложений]

ОТРЫВОК 2 (момент страха или потери):
[3-5 предложений]

ОТРЫВОК 3 (после удара — персонаж собирается):
[3-5 предложений]

Параметры голоса:
- Темп нарастания: [постепенный / рывками / волнами]
- Сенсорика: [какие чувства доминируют]
- Дистанция: [близкая / чуть отстранённая — страшнее]
- Что голос никогда не делает: [запреты серии]

═══ ПЕРСОНАЖ ═══

[Имя]:
Психологическая уязвимость (до угрозы): [что уже сломлено или надломлено]
Способ справляться: [рационализирует / отрицает / действует]
Что потеряет в этой главе: [конкретно — не абстрактно]
Граница: [что отказывается принимать — и придётся]

═══ УГРОЗА ═══

Что уже известно читателю: [список]
Что ещё неизвестно: [список — неизвестность сохраняется]
Правила угрозы: [что может, что не может — последовательно]
Что она хочет (если есть воля): [или "равнодушна" для космического]

═══ ПРАВИЛА КАЧЕСТВА ═══

ПОДЖАНР — обязательно выполнить:

ПСИХОЛОГИЧЕСКИЙ: Угроза может быть внутри. Реальность и паранойя неразличимы — намеренно. Ужас без монстра.
СВЕРХЪЕСТЕСТВЕННЫЙ: Правила угрозы последовательны. Непознаваемость важнее объяснения.
ВЫЖИВАНИЯ: Физические ограничения точны. Каждая потеря реальна и необратима. Компетентность не гарантирует выживание.
ГОТИЧЕСКИЙ: Атмосфера и место — полноправные персонажи. Прошлое давит на настоящее физически.
КОСМИЧЕСКИЙ: Угроза равнодушна — не злобна. Масштаб несоразмерен человеческому. Понимание разрушает.

ЗАПРЕЩЕНО:
- Страх названо прямо: "он почувствовал ужас" → заменить физическим ощущением
- Угроза объяснена полностью в этой главе
- Все выживают без потерь
- Спасение из ниоткуда
- Монстр некомпетентен в кульминации
- Клише из ai_cliches.md

ОБЯЗАТЕЛЬНО:
- Что-то теряется в этой главе (понимание, человек, иллюзия безопасности)
- Финальная строка создаёт новый страх — не закрывает старый
- Сенсорика: не только зрение (звук, запах, температура, текстура)

═══ СТРУКТУРА (2500-3000 слов) ═══

ТИП: [первый контакт / психологический слом / осознание / ловушка / потеря]

ВНЕШНЯЯ ЗАДАЧА: [что происходит]
ПСИХОЛОГИЧЕСКАЯ ЗАДАЧА: [что разрушается внутри]
ПОТЕРЯ: [что теряется конкретно]

- Крюк (150 слов): деталь которая не вписывается
- Нарастание (60%): удушение, не взрыв
- Удар (15%): момент — короткие предложения
- После (25%): медленно, новое понимание
```

---

## ПОЛЬЗОВАТЕЛЬСКИЙ ПРОМПТ

```
Глава [номер]. Тип: [первый контакт / слом / осознание / ловушка].

КОНТЕКСТ: [2-3 предложения]

ПЕРСОНАЖ: [состояние, уязвимость, что знает об угрозе]
УГРОЗА: [что это в этой сцене]

ЗАДАЧА ГЛАВЫ: [одно предложение — конкретно]
ЧТО ТЕРЯЕТСЯ: [конкретно]
НОВОЕ ПОНИМАНИЕ ПОСЛЕ: [что читатель и персонаж знают теперь]

ЗАКАНЧИВАЕТСЯ НА: [следующий шаг страха, не закрытие]

Объём: 2500-3000 слов.
```
