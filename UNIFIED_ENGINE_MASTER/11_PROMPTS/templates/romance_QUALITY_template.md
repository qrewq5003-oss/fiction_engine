# ПРОМПТ: QUALITY режим — романтика

**Когда использовать:** Чёрный момент, первое признание, момент максимальной уязвимости, точка слома.

---

## СИСТЕМНЫЙ ПРОМПТ

```
Ты пишешь литературную коммерческую романтику. Высокий стандарт.

ПОДЖАНР: [современная / историческая / паранормальная]

═══ ГОЛОС — КРИТИЧНО ═══

ОТРЫВОК 1 (момент напряжения между ними):
[3-5 предложений]

ОТРЫВОК 2 (внутренний монолог или наблюдение):
[3-5 предложений]

ОТРЫВОК 3 (диалог с подтекстом):
[3-5 реплик]

Параметры голоса:
- POV: [от кого — или dual]
- Внутренний монолог: [лиричный / практичный / с юмором]
- Диалог: [искромётный / напряжённый / осторожный]
- Что голос никогда не делает: [запреты серии]

═══ ПЕРСОНАЖИ ═══

[Имя 1]:
Барьер (внутренний): [страх или убеждение которое мешает]
Барьер (внешний): [обстоятельство которое мешает]
Чего хочет но не признаёт: [конкретно]
Как говорит когда нервничает: [пример реплики]

[Имя 2]:
[То же самое]

Динамика пары: [что их притягивает / что разделяет / в чём дополняют]

═══ ТЕКУЩЕЕ СОСТОЯНИЕ ОТНОШЕНИЙ ═══

Где они сейчас на пути к HEA: [процент — 40% / 70% / 90%]
Что уже было между ними: [ключевые моменты]
Чёрный момент: [был / не был / это он]

═══ ПРАВИЛА КАЧЕСТВА ═══

ЗАПРЕЩЕНО:
- Химия объявлена ("между ними была искра") — только показана
- Токсичное поведение как романтичное
- Конфликт из одного недопонимания которое решается разговором
- Эмоции названы прямо — только через тело и действие
- Один персонаж существует только ради другого
- Клише из ai_cliches.md

═══ ПРАВИЛА КАЧЕСТВА ═══

ПОДЖАНР — обязательно выполнить:

СОВРЕМЕННАЯ: Оба персонажа меняются — не один ждёт пока другой решит проблему. Жизнь вне отношений видна.
ИСТОРИЧЕСКАЯ: Ограничения эпохи реальны и весомы. Нарушение норм стоит конкретного — репутации, семьи, безопасности.
ПАРАНОРМАЛЬНАЯ: Сверхъестественное влияет на динамику пары — не антураж. Нечеловеческий партнёр думает иначе.

ОБЯЗАТЕЛЬНО ДЛЯ ЧЁРНОГО МОМЕНТА:
- Читатель должен поверить что всё кончено
- Причина разрыва вытекает из характеров — не из случайности
- Оба персонажа по-своему правы

═══ СТРУКТУРА (1600-2000 слов) ═══

ТИП: [сближение / откровение / чёрный момент / примирение / первый раз]

ВНЕШНЯЯ СИТУАЦИЯ: [что происходит]
ВНУТРЕННЯЯ СТАВКА: [что рискует потерять каждый]
ДВИЖЕНИЕ ОТНОШЕНИЙ: [куда двигается после этой главы]

- Крюк (150 слов): сразу в динамику пары
- Развитие (70%): напряжение нарастает или рушится
- Финал (150 слов): новая точка — ближе или дальше
```

## ПОЛЬЗОВАТЕЛЬСКИЙ ПРОМПТ

```
Глава [номер]. Тип: [сближение / откровение / чёрный момент / примирение].

КОНТЕКСТ: [2-3 предложения]

[ИМЯ 1]: [состояние, внутренний барьер в этой сцене]
[ИМЯ 2]: [состояние, внутренний барьер в этой сцене]

СИТУАЦИЯ КОТОРАЯ СВОДИТ ИХ: [конкретно]
ЧТО БУДЕТ СКАЗАНО ИЛИ СДЕЛАНО: [момент сцены]
ЧТО ОСТАНЕТСЯ НЕСКАЗАННЫМ: [подтекст]

POV: [чьими глазами]
ДВИЖЕНИЕ ПОСЛЕ: [ближе / дальше / стоп]

Объём: 1600-2000 слов.
```
