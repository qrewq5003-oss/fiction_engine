# ПРОМПТ: Фиксация голоса серии

**Когда использовать:** Один раз перед началом серии. Результат вставляется в каждый промпт генерации.  
**Проблема которую решает:** Голос теряется между главами потому что GPT каждый раз начинает с чистого листа.

---

## ШАГ 1 — ПОДАЙ ЭТОТ ПРОМПТ В CLAUDE

```
Я пишу серию фэнтези. Вот три отрывка из моего текста (или из текста-эталона в нужном стиле).
Твоя задача — извлечь голос и зафиксировать его в формате который можно вставить в промпт для GPT.

ОТРЫВОК 1 (экшн/напряжение):
[вставь]

ОТРЫВОК 2 (диалог):
[вставь]

ОТРЫВОК 3 (описание/атмосфера):
[вставь]

Верни:
1. Средняя длина предложения (короткие <8 слов / средние 8-15 / длинные >15 / смешанные)
2. Как строится диалог (атрибуция, действие вокруг реплик, подтекст)
3. Как передаются эмоции (прямо / через физику / через действие)
4. Характерные синтаксические приёмы (если есть — повторы, инверсии, обрывы)
5. Лексика (простая / сложная / специфическая — примеры)
6. Что никогда не встречается в этом тексте
7. Три предложения которые лучше всего передают голос — для вставки в промпт как эталон
```

---

## ШАГ 2 — ЗАФИКСИРУЙ РЕЗУЛЬТАТ

Сохрани ответ Claude в файл `my_project/voice_profile.md`.

Структура файла:
```
# Голос серии [название]

## Параметры
Длина предложений: [результат]
Диалог: [результат]
Эмоции: [результат]
Приёмы: [результат]
Лексика: [результат]
Запреты: [результат]

## Эталонные предложения
[три предложения из шага 1]

## Контрольные отрывки
[три исходных отрывка — для сверки при редактуре]
```

---

## ШАГ 3 — ИСПОЛЬЗУЙ В КАЖДОМ ПРОМПТЕ

В блок ГОЛОС системного промпта вставляй:
1. Эталонные предложения (не описание — буквально сами предложения)
2. Три параметра которые чаще всего теряются у GPT (обычно: длина предложений, подтекст в диалоге, способ передачи эмоций)

---

## ПОЧЕМУ ЭТО РАБОТАЕТ

GPT теряет голос по одной причине: в каждом новом запросе он оптимизирует под "хорошую прозу вообще" — а не под конкретный голос.

Эталонные предложения — это не инструкция, это образец для имитации на уровне ритма и лексики. GPT значительно лучше воспроизводит конкретный ритм чем следует абстрактному описанию "пиши коротко и атмосферно".

Три разных отрывка (экшн / диалог / описание) закрывают все режимы которые встречаются в главе — GPT не переключается в дефолтный режим когда сцена меняется.

---

## ПРОВЕРКА ГОЛОСА ПОСЛЕ ГЕНЕРАЦИИ

Промпт для быстрой проверки (подай в Claude):
```
Сравни два текста по голосу. Скажи только: что потеряно, что добавлено лишнего, насколько близко по шкале 1-10.

ЭТАЛОН:
[вставь один из контрольных отрывков]

СГЕНЕРИРОВАННЫЙ ТЕКСТ:
[вставь абзац из новой главы того же типа]
```

Если ниже 7 — смотри что именно потеряно и добавь в системный промпт как явный запрет или требование.
