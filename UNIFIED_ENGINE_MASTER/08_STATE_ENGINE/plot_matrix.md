# PLOT MATRIX

**Модуль:** 06_STATE_ENGINE/plot_matrix.md  
**Назначение:** Управление множественными сюжетными линиями в длинных сериях

---

## 🎯 НАЗНАЧЕНИЕ

Plot Matrix визуализирует и отслеживает:
- Все активные сюжетные линии (главные и побочные)
- Их пересечения и взаимодействия
- Прогресс каждой линии
- Моменты конвергенции (когда линии сходятся)
- Моменты дивергенции (когда линии расходятся)

**Для чего:** В сериях 100+ глав бывает 5-15 сюжетных линий. Plot Matrix помогает не потерять ни одну и создать удовлетворяющую конвергенцию.

---

## 📊 СТРУКТУРА МАТРИЦЫ

### Типы сюжетных линий:

**1. MAIN (Главные)** — 1-3 линии
- Основной конфликт истории
- Разрешаются в финале
- Присутствуют в 60%+ глав

**2. SUBPLOT (Побочные)** — 3-7 линий
- Поддерживают главную
- Могут разрешиться раньше финала
- Присутствуют в 30-50% глав

**3. ARC (Арки персонажей)** — 2-5 линий
- Развитие конкретного персонажа
- Могут пересекаться с основными
- Присутствуют периодически

**4. MYSTERY (Загадки)** — 1-3 линии
- Вопросы, раскрывающиеся медленно
- Hints разбросаны по главам
- Revelation в ключевых моментах

## 🔗 ПЕРЕСЕЧЕНИЯ ЛИНИЙ

### Типы пересечений:

**1. SUPPORT (Поддержка)**
```
Линия A помогает линии B
Пример: Романтическая линия даёт ГГ мотивацию в главной линии
```

**2. CONFLICT (Конфликт)**
```
Линия A мешает линии B
Пример: Конфликт с начальством тормозит расследование
```

**3. REVELATION (Откровение)**
```
Линия A раскрывает информацию для линии B
Пример: Побочная линия раскрывает ключ к главной загадке
```

**4. CONVERGENCE (Схождение)**
```
Линии A и B сливаются в одну
Пример: Личная месть + официальное расследование = одна цель
```

**5. DIVERGENCE (Расхождение)**
```
Линия A разделяется на B и C
Пример: Одно дело разветвляется на два
```

## 📈 УПРАВЛЕНИЕ ПРОГРЕССОМ

### Отслеживание прогресса:

**Формула:**
```
Progress = (Current_Chapter - Start_Chapter) / (End_Chapter - Start_Chapter)
```

**Пример:**
```
Линия: гл. 120-200 (80 глав)
Текущая: гл. 150
Прогресс: (150-120)/(200-120) = 30/80 = 37.5%
```

**Проверка:**
- Если прогресс < 30% на середине — **линия медленная**
- Если прогресс > 70% на середине — **линия быстрая**
- Оптимально: прогресс ≈ позиция в общей структуре

---

### Балансировка линий:

**Правило 60/30/10:**
- 60% времени — главные линии
- 30% времени — побочные линии
- 10% времени — загадки и арки

**Проверка баланса:**
```
Главы 100-110 (10 глав):
- Главная линия: 6 глав (60%) ✅
- Побочные: 3 главы (30%) ✅
- Загадки: 1 глава (10%) ✅
```

## 🎨 КОНВЕРГЕНЦИЯ (Схождение линий)

### Типы конвергенции:

**1. SOFT CONVERGENCE (Мягкое)**
```
Линии касаются, но остаются отдельными
Пример: Персонаж из побочной линии помогает в главной
```

**2. HARD CONVERGENCE (Жёсткое)**
```
Линии сливаются в одну
Пример: Личная месть и расследование становятся одним делом
```

**3. CLIMAX CONVERGENCE (Кульминационное)**
```
Все линии сходятся в финале
Пример: Все враги, все союзники, все тайны — в одной сцене
```

---

### Планирование конвергенции:

**Шаги:**

1. **Определи момент** (какая глава?)
2. **Выбери линии** (какие сойдутся?)
3. **Определи тип** (soft/hard/climax?)
4. **Создай причину** (почему они сходятся?)
5. **Спланируй последствия** (что изменится?)

**Пример:**
```yaml
convergence_event:
  chapter: 180
  threads: [main_001, main_002, sub_002, mystery_001]
  type: "climax"
  trigger: "ГГ идёт на финальную конфронтацию"
  how_they_converge:
    - main_001: "Убийца партнёра там"
    - main_002: "Коррупционеры там"
    - sub_002: "Начальник помогает ГГ"
    - mystery_001: "Тайна прошлого раскрывается"
  result: "Все конфликты разрешаются в одной сцене"
  tension_peak: 0.95
```

## 🔥 КРИТИЧЕСКИЕ ПРАВИЛА

1. **Не теряй линии**
   - Каждая начатая линия должна быть разрешена
   - Или явно оставлена открытой (для сиквела)

2. **Балансируй время**
   - Не 20 глав подряд только побочная линия
   - Главная линия должна появляться регулярно

3. **Не перегружай**
   - Максимум 3-4 активные линии одновременно
   - Остальные на паузе или завершены

4. **Создавай пересечения**
   - Линии не должны существовать изолированно
   - Минимум 2-3 пересечения на 50 глав

5. **Планируй конвергенцию**
   - Финал должен свести большинство линий
   - Читатель должен видеть связь

## 📝 ИТОГ

Plot Matrix = **навигация по сюжету**.

Для серий 100+ глав с 5-10 линиями это **необходимость**.

Без него — потерянные линии, дисбаланс, неудовлетворительный финал.
С ним — связный, насыщенный сюжет с satisfying конвергенцией.
