# WRITING GUIDE: КОМПОЗИЦИЯ СЦЕНЫ

**Модуль:** 06_scene_structure.md  
**Размер:** ~3KB  
**Зависимости:** META_RULES.yaml

---

## 🎯 ЦЕЛЬ

Каждая сцена = мини-история с началом, серединой и концом.

---

## 📋 СТРУКТУРА СЦЕНЫ

### ФОРМУЛА: ЦЕЛЬ → КОНФЛИКТ → ИЗМЕНЕНИЕ

**Правило из META:** R06 (hard rule)  
_Каждая сцена меняет знание/отношения/мир/цель персонажа_

```
1. ЦЕЛЬ: Что персонаж хочет в этой сцене?
2. КОНФЛИКТ: Что мешает?
3. ИЗМЕНЕНИЕ: Что изменилось к концу?
```

---

## 🎨 ДЕТАЛЬНО

### 1. ЦЕЛЬ СЦЕНЫ

**У персонажа должна быть конкретная цель.**

```
❌ ПЛОХО (нет цели):
Иван пришёл в кафе. Выпил кофе. Ушёл.

✅ ХОРОШО (есть цель):
Иван пришёл в кафе встретиться с информатором. 
[Цель: получить информацию]
```

**Цели бывают:**
- Внешние (получить информацию, найти ключ, сбежать)
- Внутренние (решиться признаться, преодолеть страх)
- Оба одновременно (лучший вариант!)

### 2. КОНФЛИКТ

**Что-то должно пойти не так.**

```
❌ БЕЗ КОНФЛИКТА:
Иван встретился с информатором. Получил информацию. Ушёл.

✅ С КОНФЛИКТОМ:
Иван встретился с информатором. Тот требует больше денег. 
Иван торгуется. Информация оказывается неполной.
```

**Типы конфликта:**
- Человек vs человек (оппонент мешает)
- Человек vs обстоятельства (не хватает времени, ресурсов)
- Человек vs себя (внутренняя борьба)

### 3. ИЗМЕНЕНИЕ (OUTCOME)

**К концу сцены что-то ДОЛЖНО измениться.**

```
ЧТО МОЖЕТ ИЗМЕНИТЬСЯ:
- Знание (узнал новую информацию)
- Отношения (поссорился, помирился, влюбился)
- Мир (что-то произошло во внешнем мире)
- Цель (цель изменилась или персонаж к ней ближе/дальше)
- Внутреннее состояние (принял решение, осознал)
```

**Проверка сцены:**
- [ ] Если вырезать сцену, сюжет сломается? → Да = хорошая сцена

## 🎭 ТИПЫ СЦЕН

### ACTION SCENE (экшен)
```
Цель: Сбежать от преследователей
Конфликт: Они быстрее, вооружены
Изменение: Герой ранен, но теперь знает, кто за ним охотится
```

### DIALOGUE SCENE (диалог)
```
Цель: Узнать правду о прошлом отца
Конфликт: Мать не хочет говорить, скрывает
Изменение: Узнал часть правды, но это породило новые вопросы
```

### DESCRIPTION SCENE (атмосфера)
```
Цель: Найти убежище
Конфликт: Все места заняты, опасны или разрушены
Изменение: Нашёл временное укрытие, но понял — преследователи близко
```

### REFLECTION SCENE (размышление)
```
Цель: Понять, что делать дальше
Конфликт: Все варианты плохи
Изменение: Принял решение (пусть и болезненное)
```

### REVELATION SCENE (открытие)
```
Цель: Проверить улику
Конфликт: Улика не сходится, всё сложнее
Изменение: Осознал — обвиняет не того человека
```

## 🔗 LINKING SCENES (связь сцен)

**Каждая сцена должна "тянуть" в следующую.**

### Способы связи:

**1. ВОПРОС**
```
Конец сцены 1: Иван услышал шаги за дверью. Кто это?
Начало сцены 2: Он распахнул дверь...
```

**2. ИЗМЕНЕНИЕ ЦЕЛИ**
```
Конец сцены 1: Узнал, что ключ у Марии.
Начало сцены 2: Ехал к Марии.
```

**3. CLIFFHANGER**
```
Конец сцены 1: Выстрел. Темнота.
Начало сцены 2: Иван открыл глаза. Больница.
```

**4. ВРЕМЕННОЙ ПЕРЕХОД**
```
Конец сцены 1: Это было утро. К вечеру всё изменилось.
Начало сцены 2: [6 часов спустя]
```

## 🔧 ВХОДЫ И ВЫХОДЫ ИЗ СЦЕНЫ

### ВХОД: Начни IN MEDIAS RES

```
❌ МЕДЛЕННЫЙ ВХОД:
Иван проснулся. Умылся. Оделся. Позавтракал. Вышел из дома. 
Сел в машину. Поехал в полицейский участок.

✅ БЫСТРЫЙ ВХОД:
Иван ворвался в участок. — Где капитан?
```

**Правило:** Начинай сцену как можно ближе к действию.

### ВЫХОД: Заканчивай на напряжении

```
❌ ВЯЛЫЙ ВЫХОД:
Иван получил информацию. Поблагодарил информатора. 
Вышел из кафе. Сел в машину. Поехал домой.

✅ СИЛЬНЫЙ ВЫХОД:
Иван получил информацию. Встал. Замер. На столе лежал 
конверт — с его именем. Откуда?
```

**Правило:** Заканчивай на вопросе, решении или изменении.

## 🎯 ПЕЙСИНГ СЦЕН

**Чередуй интенсивность:**

```
Глава 1: Интенсивность 8/10 (экшен)
Глава 2: Интенсивность 4/10 (размышление)
Глава 3: Интенсивность 7/10 (диалог с конфликтом)
Глава 4: Интенсивность 3/10 (worldbuilding)
Глава 5: Интенсивность 9/10 (поворотный момент)
```

**Правило из META:** Не >2 низких (1-4/10) сцен подряд.

## ❌ ЧАСТЫЕ ОШИБКИ

### 1. Сцена без цели
```
❌: Персонаж бесцельно бродит, думает, смотрит в окно.
✅: У каждого действия есть причина.
```

### 2. Отсутствие конфликта
```
❌: Всё идёт гладко, цель достигнута легко.
✅: Путь к цели труден.
```

### 3. Сцена ничего не меняет
```
❌: В конце сцены всё как в начале.
✅: Что-то изменилось (знание/отношения/мир/цель).
```

### 4. Медленный вход/выход
```
❌: Долгие подготовки, затянутые концовки.
✅: In medias res → быстрый выход.
```

---

## ✅ ЧЕКЛИСТ СЦЕНЫ

Перед финализацией сцены:

- [ ] У персонажа есть конкретная цель
- [ ] Есть конфликт (что-то мешает)
- [ ] Что-то изменилось (знание/отношения/мир/цель)
- [ ] Вход быстрый (близко к действию)
- [ ] Выход на напряжении
- [ ] Сцена связана со следующей (вопрос/изменение цели/cliffhanger)
- [ ] Если вырезать — сюжет сломается

---

## 💡 ФОРМУЛА ИДЕАЛЬНОЙ СЦЕНЫ

```
1. Быстрый вход (in medias res)
2. Ясная цель персонажа
3. Конфликт/препятствие
4. Попытки преодоления
5. Изменение (успех/неудача/осложнение)
6. Выход на напряжении → следующая сцена
```
