# WRITING GUIDE: ЭМОЦИИ И ВНУТРЕННИЙ МИР

**Модуль:** 04_emotions.md  
**Размер:** ~3KB  
**Зависимости:** META_RULES.yaml

---

## 🎯 ЦЕЛЬ

Показывать эмоции через физические проявления и действия, а не называть их.

---

## 📋 SHOW VS TELL

**Золотое правило:** 60% SHOW / 40% TELL

### Что такое SHOW
**Показывай эмоцию через:**
- Физические реакции
- Действия персонажа
- Восприятие окружающего
- Мысли (но не "он был зол")

### Что такое TELL
**Называй эмоцию прямо:**
- Допустимо в 40% случаев
- Когда нужна скорость
- Для второстепенных эмоций

## 🎨 ТЕХНИКА SHOW

### ФИЗИЧЕСКИЕ ПРОЯВЛЕНИЯ ЭМОЦИЙ

**СТРАХ:**
```
❌ TELL: Иван испугался.

✅ SHOW: 
Сердце забилось быстрее. Ладони вспотели. Он сделал шаг назад.
```

**ГНЕВ:**
```
❌ TELL: Мария разозлилась.

✅ SHOW:
Мария сжала кулаки. Ногти впились в ладони. Челюсть напряглась.
```

**ГРУСТЬ:**
```
❌ TELL: Ему было грустно.

✅ SHOW:
Он отвернулся к окну. Горло сжалось. Моргнул, прогоняя влагу.
```

**РАДОСТЬ:**
```
❌ TELL: Она обрадовалась.

✅ SHOW:
Улыбка сама расплылась по лицу. Она подпрыгнула, не сдержавшись.
```

**ВОЛНЕНИЕ:**
```
❌ TELL: Он нервничал.

✅ SHOW:
Пальцы барабанили по столу. Взгляд метался от двери к часам.
```

**ВЛЮБЛЁННОСТЬ:**
```
❌ TELL: Он влюбился.

✅ SHOW:
Когда она вошла, воздух стал чище. Он забыл, что хотел сказать.
```

## 🔧 СЛОЖНЫЕ ЭМОЦИИ

### MIXED EMOTIONS (смесь чувств)

**Не всё однозначно. Покажи сложность.**

```
❌ ПЛОСКО:
Иван был зол на неё.

✅ СЛОЖНО:
Иван смотрел на неё — злость, жалость, что-то ещё, чему он 
не находил названия. Он развернулся и ушёл.
```

### ПОДАВЛЕННЫЕ ЭМОЦИИ

**Показывай попытку скрыть.**

```
Она улыбнулась. Слишком широко. Руки дрожали, но она сунула их в карманы.
```

### ЭМОЦИИ ЧЕРЕЗ ВОСПРИЯТИЕ

**Эмоция меняет то, как персонаж видит мир.**

```
ДЕПРЕССИЯ:
Серое небо. Серые стены. Серые лица людей. Всё серое.

ВЛЮБЛЁННОСТЬ:
Даже дождь казался прекрасным. Капли стекали по стеклу, 
как в немом кино.

ПАРАНОЙЯ:
Каждый взгляд — подозрителен. Каждый шаг за спиной — угроза.
```

## 🎭 ВНУТРЕННИЙ МОНОЛОГ

**ПРАВИЛА:**
1. Короткий (не >3 предложений подряд)
2. Отражает голос персонажа
3. Не дублирует очевидное

```
❌ ПЛОХО:
"Я зол. Очень зол. Я не могу поверить, что она это сделала."

✅ ХОРОШО:
Три года. Три чёртовых года. И вот так просто?
```

### МЫСЛИ vs ДЕЙСТВИЯ

**Баланс:** 30% мысли / 70% действия

```
❌ ТОЛЬКО МЫСЛИ:
Иван думал о том, что нужно идти. Он размышлял о последствиях. 
Что если...

✅ БАЛАНС:
Идти. Надо идти. Иван встал, схватил куртку. Последствия — потом.
```

## 🔧 ЖАНРОВАЯ АДАПТАЦИЯ

### ДЕТЕКТИВ / НУАР
```
Стиль: Эмоции подавлены. Показ через циничные мысли.

Очередной труп. Иван прикурил. Должно волновать? Когда-то волновало.
```

### РОМАНТИКА
```
Стиль: Эмоции на первом плане. Физические реакции детальны.

Его взгляд задержался на её руке. Сердце пропустило удар. 
Дыхание сбилось.
```

### ХОРРОР
```
Стиль: Страх через физику. Паника конкретна.

Руки тряслись. Не слушались. Ключ выпал. Шаги за дверью ближе.
```

### ФЭНТЕЗИ
```
Стиль: Эмоции + магия. Внутренняя сила.

Гнев разгорелся внутри — буквально. Руны на коже засветились.
```

## ❌ ЧАСТЫЕ ОШИБКИ

### 1. Называние вместо показа
```
❌: Он был зол, напуган и растерян.
✅: Кулаки сжались. Шаг назад. Взгляд бегал по сторонам.
```

### 2. Клише эмоций
```
❌ ШТАМПЫ:
- Кровь стыла в жилах
- Сердце екнуло
- Мурашки по коже
- Дыхание перехватило

✅ СВЕЖО:
- Холод пополз от затылка к плечам
- Сердце словно пропустило такт
- Кожа на руках покрылась мелкими пупырышками
- Воздух застрял в горле
```

### 3. Избыток внутреннего монолога
```
❌ МНОГО:
[300 слов мыслей персонажа]

✅ БАЛАНС:
Идиот. Полный идиот. Иван ударил по рулю. Развернулся обратно.
```
