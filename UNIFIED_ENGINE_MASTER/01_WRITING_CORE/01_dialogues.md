# WRITING GUIDE: ДИАЛОГИ

**Модуль:** 01_dialogues.md  
**Размер:** ~3KB  
**Зависимости:** META_RULES.yaml, genre_catalog/{genre}.json

---

## 🎯 НАЗНАЧЕНИЕ

Техники создания естественных, функциональных диалогов, которые двигают сюжет и раскрывают персонажей.

---

## 📋 БАЗОВЫЕ ПРАВИЛА

### 1. Эм-дэш (—) для прямой речи
**Правило из META:** R01 (hard rule)

```
✅ ПРАВИЛЬНО:
— Где ты была? — Иван прикурил сигарету.
— Дома, — ответила Мария, не поднимая глаз.

❌ НЕПРАВИЛЬНО:
"Где ты была?" - Иван прикурил сигарету.
«Дома», ответила Мария.
- Где ты была?
```

### 2. Минимум атрибуции
**Принцип:** Если понятно, кто говорит — не уточняй.

```
✅ ХОРОШО:
— Ты опоздал на два часа.
— Извини. Пробки.
— Пробки. Конечно.

❌ ПЛОХО:
— Ты опоздал на два часа, — сказала она.
— Извини. Пробки, — ответил он.
— Пробки. Конечно, — произнесла она с сарказмом.
```

**Когда нужна атрибуция:**
- Более 2 персонажей в сцене
- Переход между говорящими неочевиден
- Нужно показать действие или эмоцию

### 3. Действие вместо "сказал"
**Показывай эмоцию через действия, а не слова.**

```
❌ ПЛОХО:
— Я не верю тебе, — сказал он с недоверием.
— Это правда, — ответила она нервно.

✅ ХОРОШО:
— Я не верю тебе. — Он отвернулся к окну.
— Это правда. — Мария сжала ладони.
```

## 🎨 ТЕХНИКИ ДИАЛОГОВ

### ПОДТЕКСТ — главное оружие
**Люди редко говорят прямо. Подтекст важнее текста.**

```
❌ БЕЗ ПОДТЕКСТА:
— Я тебя люблю.
— Я тоже тебя люблю.

✅ С ПОДТЕКСТОМ:
— Ты собираешься уходить?
— Ещё нет.
— «Ещё»?
Молчание.
```

**Подтекст через:**
- Паузы и молчание
- Уклонение от ответа
- Смена темы
- Действия вместо слов

### ЕСТЕСТВЕННОСТЬ РЕЧИ
**Люди не говорят идеальными предложениями.**

```
❌ НЕЕСТЕСТВЕННО:
— Я думаю, что мы должны обсудить то, что произошло вчера вечером.

✅ ЕСТЕСТВЕННО:
— Насчёт вчерашнего… нам стоит поговорить.
```

**Приёмы:**
- Незавершённые фразы
- Междометия (хм, ну, эм)
- Повторы (в меру!)
- Сленг и идиомы персонажа

### ИНДИВИДУАЛЬНОСТЬ ГОЛОСА
**Каждый персонаж говорит по-своему.**

```
Детектив (циничный, 40 лет):
— Ещё одна ночь, ещё один труп. Оригинально.

Молодая копиня (идеалистка, 25 лет):
— Нам нужно найти убийцу. Семья жертвы заслуживает ответов.

Капитан (бюрократ, 55 лет):
— Петров, у вас есть 48 часов. Потом дело переходит к федералам.
```

**Факторы голоса:**
- Возраст (молодёжный сленг vs формальность)
- Образование (простые vs сложные слова)
- Профессия (жаргон)
- Регион (диалект, акцент)
- Личность (оптимист vs пессимист)

### РИТМ И ТЕМП
**Короткие реплики = напряжение. Длинные = размышление.**

```
НАПРЯЖЁННАЯ СЦЕНА (короткие реплики):
— Где ключ?
— Какой ключ?
— Не ври.
— Я не…
— Где. Ключ.

РАЗМЫШЛЕНИЕ (длинные реплики):
— Знаешь, я всю жизнь думал, что делаю правильные вещи. 
Что если я просто следую правилам, всё будет в порядке. 
Но теперь я понимаю… правила — это иллюзия.
```

## 🎭 ФУНКЦИИ ДИАЛОГА

### Диалог должен выполнять 2+ функции одновременно:

1. **Двигать сюжет** — новая информация, решение, действие
2. **Раскрывать персонажа** — характер, мотивация, прошлое
3. **Создавать конфликт** — противоречие, напряжение
4. **Устанавливать отношения** — динамика между персонажами
5. **Задавать атмосферу** — тон сцены

```
❌ ОДНОМЕРНЫЙ ДИАЛОГ (только информация):
— Убийство было в 22:00. Оружие — нож. Следов нет.

✅ МНОГОМЕРНЫЙ ДИАЛОГ (информация + характер + конфликт):
— Убийство в десять вечера, — Мария захлопнула папку. — Нож. 
Никаких следов.
— Как удобно для вас, — Иван не отрывал взгляд от её лица.
— Что вы хотите этим сказать?
— Ничего. Просто… очень чистая работа.
```

**Анализ:**
- ✅ Информация (время, оружие, следы)
- ✅ Характер (Мария деловая, Иван подозрительный)
- ✅ Конфликт (недоверие между ними)
- ✅ Отношения (напряжение, возможная враждебность)

## 🔧 ЖАНРОВАЯ АДАПТАЦИЯ

### ДЕТЕКТИВ / НУАР
```
Стиль: Короткие циничные реплики, минимум эмоций, подтекст

— Кто-то хочет, чтобы ты замолчал.
— Очередь длинная.
— Весело живёшь.
— Пока живу.
```

### ФЭНТЕЗИ
```
Стиль: Формальность (если высокое), мифологические отсылки

— Клянусь Древними, я не предавал орден.
— Клятвы нарушаются легче, чем произносятся.
```

### РОМАНТИКА
```
Стиль: Эмоциональность, уязвимость, chemistry

— Почему ты не можешь просто сказать, что чувствуешь?
— Потому что это всё меняет.
— Может, пора?
```

### ХОРРОР
```
Стиль: Прерывистые фразы, страх, недосказанность

— Ты слышал?
— Что?
— Тихо. Слушай.
Тишина.
— Там никого…
— Теперь нет.
```

### ТРИЛЛЕР / ЭКШЕН
```
Стиль: Короткие команды, динамика, urgency

— Сколько?
— Трое. Вооружены.
— Выход?
— Один. Справа.
— Идём.
```

## ❌ ЧАСТЫЕ ОШИБКИ

### 1. Избыточная атрибуция
```
❌ ПЛОХО:
— Привет, — сказал он.
— Привет, — ответила она.
— Как дела? — спросил он.
— Нормально, — ответила она.

✅ ХОРОШО:
— Привет.
— Привет.
— Как дела?
— Нормально. — Она отвернулась.
```

### 2. "Nose-on-the-face" диалог
**Когда персонажи говорят очевидное друг другу.**

```
❌ ПЛОХО:
— Как ты знаешь, я твоя сестра, и мы выросли вместе в Москве.

✅ ХОРОШО:
— Помнишь, как мы с тобой в Измайлово…
— Не надо.
```

### 3. Отсутствие подтекста
```
❌ ПЛОХО:
— Я злюсь на тебя.
— Почему?
— Потому что ты предал меня.

✅ ХОРОШО:
— Три года. — Она не смотрела на него.
— Я могу объяснить.
— Можешь. Но я не хочу слушать.
```

### 4. Все персонажи говорят одинаково
```
❌ ПЛОХО:
Все говорят формальным языком со сложными предложениями.

✅ ХОРОШО:
Профессор: "Артефакт датируется третьим веком до нашей эры."
Копатель: "Нашёл штуку. Старая."
```

## ✅ ЧЕКЛИСТ КАЧЕСТВЕННОГО ДИАЛОГА

Перед финализацией диалога проверь:

- [ ] Выполняет 2+ функции (сюжет + характер + конфликт)
- [ ] Есть подтекст (не всё сказано прямо)
- [ ] Каждый персонаж звучит уникально
- [ ] Атрибуция минимальна и функциональна
- [ ] Нет "nose-on-the-face" моментов
- [ ] Ритм соответствует эмоции сцены
- [ ] Естественная речь (не идеальные предложения)
- [ ] Соответствует жанру

## 💡 ПРИМЕРЫ ИЗ ЛИТЕРАТУРЫ

### Хемингуэй (мастер подтекста):
```
— Вы хотите выпить?
— Все хотят выпить.
— Я хочу, чтобы вы выпили со мной.
— Мы не знакомы.
— Конечно, не знакомы.
```
**Что не сказано:** Одиночество, отчаяние, желание связи.

### Леонард (нуар-диалоги):
```
— Что ты здесь делаешь?
— То же, что и ты. Только я лучше одета.
```
**Характер через реплику:** Циничность, уверенность, ирония.
