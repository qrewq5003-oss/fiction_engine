# WRITING GUIDE: ОПИСАНИЯ

**Модуль:** 02_descriptions.md  
**Размер:** ~3KB  
**Зависимости:** META_RULES.yaml, genre_catalog/{genre}.json

---

## 🎯 НАЗНАЧЕНИЕ

Техники создания живых, атмосферных описаний, которые не тормозят повествование.

---

## 📋 БАЗОВЫЕ ПРАВИЛА

### 1. Уникальные атмосферные детали
**Правило из META:** R03 (hard rule)

**Требование:** 1-2 уникальные НЕканоничные сенсорные детали на атмосферную сцену.

```
❌ ШТАМП:
В воздухе висело напряжение. Сердце екнуло. Кровь стыла в жилах.

✅ УНИКАЛЬНАЯ ДЕТАЛЬ:
Запах мокрого бетона смешивался с озоном после грозы.
```

### 2. Избегать перегруженности
**Правило:** Описания должны быть короткими и функциональными.

```
❌ ПЕРЕГРУЖЕНО (300 слов описания комнаты):
Комната была просторной, около тридцати квадратных метров. 
Стены были выкрашены в светло-бежевый цвет, который...
[ещё 250 слов]

✅ ФУНКЦИОНАЛЬНО (2-3 предложения):
В комнате пахло старой бумагой и табаком. Венецианская штукатурка 
облупилась в углах, обнажив кирпичную кладку.
```

**Золотое правило:** Если деталь не важна для сюжета, эмоции или атмосферы — выбрось её.

### 3. Show через действие персонажа
**Не описывай статично — покажи через восприятие персонажа.**

```
❌ СТАТИЧНОЕ ОПИСАНИЕ:
Комната была грязной. Везде валялся мусор.

✅ ЧЕРЕЗ ПЕРСОНАЖА:
Иван поморщился. Под ногами хрустела разбитая посуда, 
на столе — разложившийся обед недельной давности.
```

## 🎨 ТЕХНИКИ ОПИСАНИЙ

### СЕНСОРНОСТЬ — задействуй 5 чувств

**НЕ только визуал!** Запах, звук, тактильность, вкус.

```
❌ ТОЛЬКО ВИЗУАЛ:
Улица была тёмной. Редкие фонари освещали асфальт.

✅ ВСЕ ЧУВСТВА:
Запах гнилых овощей из помойки смешивался с выхлопами. 
Асфальт, ещё тёплый после дневной жары, обжигал ладони. 
Где-то вдали лаяла собака.
```

**Распределение:**
- Зрение: 40%
- Звук: 25%
- Запах: 20%
- Тактильность: 10%
- Вкус: 5% (редко, но метко)

### ДЕТАЛЬ вместо ОБЩЕГО

```
❌ ОБЩЕЕ:
Он был богатым человеком.

✅ ДЕТАЛЬ:
Часы на его запястье стоили как квартира в центре.
```

```
❌ ОБЩЕЕ:
Она была красивой.

✅ ДЕТАЛЬ:
Когда она улыбалась, в уголках глаз появлялись морщинки.
```

**Принцип:** Одна конкретная деталь > десять общих слов.

### АТМОСФЕРА через ДЕТАЛИ

**Создавай настроение через правильные детали.**

```
МРАЧНАЯ АТМОСФЕРА:
Плесень расползалась по углам чёрными кляксами. 
В коридоре капала вода — монотонно, без остановки.

УЮТНАЯ АТМОСФЕРА:
Запах корицы и яблок плыл из кухни. Камин потрескивал, 
отбрасывая оранжевые блики на книжные полки.

НАПРЯЖЁННАЯ АТМОСФЕРА:
Тишина была слишком полной. Даже уличный шум не проникал 
сквозь окна. Единственный звук — его собственное дыхание.
```

### МЕТАФОРЫ И СРАВНЕНИЯ (с осторожностью!)

**Используй, но избегай избитых.**

```
❌ ИЗБИТЫЕ:
Луна, как серебряный диск.
Глаза, словно два озера.
Сердце колотилось, как молот.

✅ СВЕЖИЕ:
Луна висела над крышами, как забытая монета на дне колодца.
Его взгляд скользил по ней, не задерживаясь, словно по рекламе 
в метро.
```

**Правило:** Если метафору легко представить — она избитая.

### ЭКОНОМИЯ ОПИСАНИЙ

**Не описывай всё подряд.**

```
❌ ИЗБЫТОЧНО:
Она вошла в комнату. Комната была квадратной, с высокими 
потолками. Окна выходили на север. Пол был паркетным. 
Стены были голубыми. Мебель...

✅ ЭКОНОМНО:
Она вошла. Голые стены, пустой пол — квартира всё ещё ждала 
жильца.
```

**Описывай:**
- Что важно для сюжета
- Что создаёт атмосферу
- Что раскрывает персонажа

**НЕ описывай:**
- Банальные детали
- То, что читатель и так представит
- Фон, который не имеет значения

## 🔧 ЖАНРОВАЯ АДАПТАЦИЯ

### ДЕТЕКТИВ / НУАР
```
Стиль: Короткие, циничные описания. Акцент на детали-улики.

Грязь под ногтями. Свежая, судя по цвету — чернозём из парка. 
Парк в трёх кварталах отсюда, алиби говорит о центре города.
```

### ФЭНТЕЗИ
```
Стиль: Живописность, но без перегруза. Магия через детали.

Руны на стенах мерцали тусклым светом, пульсируя в такт его 
дыханию. Древняя магия. Опасная.
```

### ХОРРОР
```
Стиль: Атмосферность, зловещие детали, недосказанность.

Что-то хрустнуло под ногами. Он не хотел смотреть вниз. 
Но запах... запах был слишком знакомым.
```

### РОМАНТИКА
```
Стиль: Эмоциональность, сенсорность, фокус на персонажах.

Его рука легла на её плечо — тёплая, чуть шершавая от мозолей. 
Она замерла, не дыша.
```

### ЭКШЕН / ТРИЛЛЕР
```
Стиль: Минимум описаний, фокус на действии.

Коридор. Пять дверей. Две закрыты. Он пошёл к первой открытой.
```

### ЛИТЕРАТУРНАЯ ПРОЗА
```
Стиль: Метафоричность, глубина, сложные образы.

Город просыпался медленно, нехотя, как человек после слишком 
долгого сна — с тяжестью в мыслях и горечью во рту.
```

## ❌ ЧАСТЫЕ ОШИБКИ

### 1. "Описательная диарея"
```
❌ ПЛОХО:
[500 слов описания комнаты, где ничего не происходит]

✅ ХОРОШО:
Захламлённая комната. Он прошёл к столу.
```

### 2. Клише и штампы
```
❌ ШТАМПЫ:
Кровь стыла в жилах.
Сердце екнуло.
Мурашки по коже.
Дыхание перехватило.

✅ УНИКАЛЬНО:
Холод пополз от затылка к плечам.
Пальцы онемели, словно их окунули в ледяную воду.
```

### 3. Описание очевидного
```
❌ ОЧЕВИДНОЕ:
Солнце светило ярко. День был тёплым.

✅ ФУНКЦИОНАЛЬНОЕ:
Асфальт плавился под ногами. Иван пожалел, что надел пиджак.
```

### 4. Абстрактность вместо конкретики
```
❌ АБСТРАКТНО:
Он чувствовал себя плохо.

✅ КОНКРЕТНО:
Желудок сжимался в тугой узел. Руки тряслись.
```

### 5. "Информационный дамп"
```
❌ ДАМП:
Город был основан в 1703 году Петром I. Население составляет 
5 миллионов человек. Климат умеренный...

✅ ОРГАНИЧНО:
Питер всегда был городом контрастов. Дворцы соседствовали 
с хрущёвками, каналы — с промзонами.
```

## ✅ ЧЕКЛИСТ КАЧЕСТВЕННОГО ОПИСАНИЯ

Перед финализацией описания проверь:

- [ ] Есть 1-2 уникальные сенсорные детали (не штампы)
- [ ] Задействовано >1 чувства (не только визуал)
- [ ] Описание функционально (служит сюжету/атмосфере/персонажу)
- [ ] Нет перегруженности (не >3 предложений подряд)
- [ ] Конкретные детали вместо абстракций
- [ ] Показано через восприятие персонажа
- [ ] Нет клише из списка
- [ ] Соответствует жанру

## 💡 ПРИМЕРЫ ИЗ ЛИТЕРАТУРЫ

### Набоков (мастер детали):
```
"Лужи на мостовой блестели, как разбитые зеркала."
```
**Почему работает:** Визуальная метафора + неожиданное сравнение.

### Кинг (атмосфера через деталь):
```
"Дом пах старостью и забытьем, как библиотека, которую давно 
никто не посещал."
```
**Почему работает:** Запах + эмоция + конкретное сравнение.

### Хемингуэй (экономность):
```
"Холмы вдали были белыми."
```
**Почему работает:** Минимализм. Остальное — в подтексте.

## 🎨 УПРАЖНЕНИЕ

**Опиши одну и ту же комнату в разных жанрах:**

**Нуар:**
Венецианские жалюзи резали свет на полосы. Пепельница переполнена. 
Кто-то ушёл в спешке.

**Хоррор:**
Жалюзи висели криво, одна створка сломана. Что-то царапнуло пол — 
след тянулся к двери в подвал.

**Романтика:**
Солнце пробивалось сквозь жалюзи, рисуя узоры на её плече. 
Она повернулась, улыбаясь.

**Фэнтези:**
Руны на оконной раме мерцали тускло — защита слабела. Нужно 
обновлять заклинание.
