## 🎯 ЦЕЛЬ

Динамичные, визуальные экшен-сцены с правильным ритмом и ясностью.

---

## 📋 ОСНОВНЫЕ ПРИНЦИПЫ

### 1. КОРОТКИЕ ПРЕДЛОЖЕНИЯ
**Темп экшена = длина предложений.**

```
❌ МЕДЛЕННО (длинные предложения):
Иван увернулся от удара, который был направлен в его голову, 
и быстро ответил серией коротких ударов по корпусу противника.

✅ БЫСТРО (короткие предложения):
Иван уклонился. Удар прошёл мимо. Он ударил в корпус. Раз. Два. Три.
```

**Правило:** В экшене 70% коротких предложений (<8 слов).

### 2. ЯСНОСТЬ ДЕЙСТВИЯ
**Читатель должен видеть кино в голове.**

```
❌ НЕЯСНО:
Они дрались. Было много ударов.

✅ ЯСНО:
Кулак летел к лицу. Иван отбил предплечьем. Контратака — 
в челюсть. Противник качнулся.
```

### 3. ФИЗИЧЕСКИЕ ОЩУЩЕНИЯ
**Показывай боль, усталость, адреналин.**

```
❌ АБСТРАКТНО:
Было больно.

✅ ФИЗИЧЕСКИ:
Костяшки пальцев взорвались болью. Рука онемела до локтя.
```

## 🎨 ТЕХНИКИ ЭКШЕНА

### РИТМ — главное оружие

**Чередуй длину для контроля темпа:**

```
НАРАСТАНИЕ:
Тишина. [короткое]
Шаги в коридоре. [короткое]
Иван прижался к стене, сжимая пистолет. [среднее]
Дверь распахнулась. [короткое]
ВЗРЫВ ДЕЙСТВИЯ:
Выстрел. Крик. Он бросился вправо. [3 коротких подряд]
```

### ФОКУС НА КРИТИЧНОМ

**Не описывай каждое движение — только ключевые моменты.**

```
❌ ИЗБЫТОЧНО:
Он поднял правую руку, согнул локоть, сжал кулак, 
оттянул назад и нанёс удар...

✅ ФОКУС:
Замах. Удар. Хруст.
```

### СЕНСОРНОСТЬ В ЭКШЕНЕ

**Звук, запах, тактильность усиливают погружение.**

```
Запах пороха. Звон в ушах. Горячая кровь на лице.
```

### ПОСЛЕДСТВИЯ

**Показывай цену экшена.**

```
❌ БЕЗ ПОСЛЕДСТВИЙ:
Он дрался пять минут. Потом пошёл дальше.

✅ С ПОСЛЕДСТВИЯМИ:
Ребра ноют. Губа разбита. Дышать больно. Но двигаться надо.
```

## 🔧 ЖАНРОВАЯ АДАПТАЦИЯ

### БОЕВИК / ТРИЛЛЕР
```
Темп: Очень быстрый. Предложения 3-5 слов.

Выстрел. Мимо. Перекат. Ответный огонь. Попал.
```

### ФЭНТЕЗИ (магический бой)
```
Темп: Средний. Визуализация магии.

Огненный шар сорвался с его ладони. Маг противника выставил щит — 
синее свечение. Столкновение. Взрыв.
```

### ДЕТЕКТИВ (драка)
```
Темп: Средний. Грязно и реалистично.

Удар в живот. Иван согнулся, хватая воздух. Противник навис сверху. 
Стеклянная пепельница на столе. Иван схватил её. Размах. Хруст.
```

### ХОРРОР (survival)
```
Темп: Рваный. Паника + действие.

Бежать. Просто бежать. Ветка хлестнула по лицу. Не оглядываться. 
Оно сзади. Ближе. Ближе.
```

## ❌ ЧАСТЫЕ ОШИБКИ

### 1. Излишняя детализация
```
❌ ПЛОХО:
Он поднял правую руку на 45 градусов, сжал кулак, напряг бицепс...

✅ ХОРОШО:
Замах. Удар в челюсть.
```

### 2. Статичность
```
❌ ПЛОХО:
Иван дрался с врагом. Было много ударов. Он победил.

✅ ХОРОШО:
Иван уклонился. Ударил. Противник упал.
```

### 3. Потеря ориентации
```
❌ ПОТЕРЯЛИ:
Он ударил. Кто-то упал. Выстрел. Кто стрелял?

✅ ЯСНО:
Иван ударил. Первый упал. Второй стрелял. Промах.
```
