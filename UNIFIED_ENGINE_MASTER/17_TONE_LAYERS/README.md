# 17_TONE_LAYERS — тона

Тон — слой поверх жанра: как звучит глава или вся книга. Выбирается для
всего проекта (карточка «Второй жанр», группа «Тон и аудитория») или для
отдельной главы (страницы генерации и пайплайна, «Тон главы»).

В промпт идут суть, приёмы и ошибки. Примеров в файлах нет сознательно:
модель переносит примеры в текст.

Комедия и подростковая проза (YA) лежат профилями в
`05_CHARACTER_ENGINE/profiles/GENRE/` (comedic.md, young_adult.md).
