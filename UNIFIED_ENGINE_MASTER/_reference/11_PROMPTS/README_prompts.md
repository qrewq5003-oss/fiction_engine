# Промпты: Навигация

---

## КАКОЙ ПРОМПТ КОГДА ИСПОЛЬЗОВАТЬ

**Перед началом серии — один раз:**
`voice_lock.md` — зафиксируй голос серии. Результат вставляй в каждый промпт генерации.

**Генерация глав:**

| Ситуация | Промпт | Время подготовки |
|----------|--------|-----------------|
| Обычная глава, черновик | QUICK_generation.md | 5 минут |
| Важная глава, поворот, кульминация | QUALITY_generation.md | 10-15 минут |
| Финал арки, точка невозврата | MASTER_generation.md | 20-30 минут |

**После генерации:**
`pace_fix.md` — если темп провисает в середине (диагностика через Claude, правка через GPT)
`10_VALIDATION/claude_validation_prompt.md` — полная валидация главы

---

## WORKFLOW ДЛЯ ОБЫЧНОЙ ГЛАВЫ

1. Заполни `QUICK_generation.md` — вставь голос из предыдущей главы и задачу главы
2. Подай в GPT → получи черновик
3. Быстрая проверка: прочитай первый и последний абзац. Голос держится?
4. Если темп проседает → `pace_fix.md` через Claude
5. Финальная редактура вручную (5-10 минут)
6. Обнови State Engine

---

## WORKFLOW ДЛЯ ВАЖНОЙ ГЛАВЫ

1. `voice_lock.md` — обнови если давно не обновлял
2. Заполни `QUALITY_generation.md` — три отрывка для голоса обязательны
3. Подай в GPT → получи черновик
4. `claude_validation_prompt.md` → получи JSON с проблемами
5. Передай оригинал + JSON в GPT: "перепиши только указанные абзацы"
6. Финальная редактура
7. Обнови State Engine

---

## КРИТИЧЕСКОЕ ПРАВИЛО

Поле ГОЛОС в промпте — это не описание стиля словами.
Это буквальные предложения из предыдущих глав.

Плохо: "Пиши в напряжённом кинематографичном стиле с короткими предложениями."
Хорошо: "Вот три предложения из текста: [буквально сами предложения]"

GPT имитирует конкретный ритм точнее чем следует абстрактной инструкции.
Это главная причина потери голоса — и главное что исправляет voice_lock.
