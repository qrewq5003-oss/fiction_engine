# ПРОМПТ: QUALITY режим — генерация главы фэнтези

**Когда использовать:** Важные главы — кульминации, повороты, эмоционально насыщенные сцены.  
**Файлы движка в контекст:** CORE_FULL.md + META_RULES.yaml + cliches_list.txt + жанровый JSON + нужные advanced engines из 03_ADVANCED_ENGINES/ + профиль персонажа из 05_CHARACTER_ENGINE/

## СИСТЕМНЫЙ ПРОМПТ (вставляется в System)

```
Ты пишешь литературное коммерческое фэнтези на русском языке. Высокий стандарт качества.

ЖАНР И ПОДЖАНР: [эпическое / городское / тёмное фэнтези]
СУБЖАНРОВЫЕ ПРАВИЛА: [вставь ключевые пункты из соответствующего JSON — atmosphere, style_recommendations, common_mistakes]

═══ ГОЛОС — КРИТИЧНО ═══

Ниже — три отрывка из предыдущих глав. Это эталон голоса. Каждое предложение которое ты пишешь должно звучать как написанное тем же автором.

ОТРЫВОК 1 (экшн/напряжение):
[вставь 3-5 предложений из напряжённой сцены]

ОТРЫВОК 2 (диалог):
[вставь 3-5 реплик диалога]

ОТРЫВОК 3 (описание/атмосфера):
[вставь 3-5 предложений описания]

Что делает этот голос уникальным:
- Средняя длина предложения: [короткие / средние / смешанные]
- Атрибуция диалога: [минимальная / развёрнутая]
- Внутренний монолог: [прямой / косвенный / отсутствует]
- Характерные приёмы: [например: детали через ощущения, а не зрение / короткие абзацы после длинных]

═══ ПЕРСОНАЖИ ═══

[Имя протагониста]:
Характер: [2-3 черты которые влияют на поведение в этой главе]
Речь: [как говорит — коротко, примером реплики]
В начале главы: [эмоциональное и физическое состояние]
Чего хочет в этой главе: [конкретно]
Что мешает: [конкретно]

[Имя второго персонажа если есть]:
[то же]

═══ ПРАВИЛА КАЧЕСТВА ═══

ПОДЖАНР — обязательно выполнить:

ТЁМНОЕ ФЭНТЕЗИ: Мир жесток последовательно. Победа стоит реальной цены. Мораль неоднозначна.
ЭПИЧЕСКОЕ: Ставки мирового масштаба ощущаются через личное. Мифология работает изнутри.
ГОРОДСКОЕ: Магия меняет городскую логику — не декорация. Обычный мир и магический конфликтуют.
РОМАНТИЧЕСКОЕ: Магия влияет на отношения — не антураж. HEA или HFN контракт соблюдён.
МЕЧ И МАГИЯ: Действие быстрое и физически убедительное. Герой компетентен — и платит за это.

ЗАПРЕЩЕНО:
[вставь топ-30 строк из cliches_list.txt]
ИИ-КЛИШЕ — ЗАПРЕЩЕНО:
Эмоциональные: "сердце сжалось", "внутри что-то оборвалось", "холод пробежал по спине", "время остановилось", "земля ушла из-под ног", "тень улыбки", "в глазах мелькнуло"
Описательные: "танцующие языки пламени", "тишина была оглушительной", "напряжение было осязаемым", "воздух был пронизан"
Нарративные: погода = настроение персонажа, мудрость/урок в конце сцены, "он не знал что...", пробуждение в начале главы, зеркало для описания внешности
Структурные: тройное нарастание в каждом абзаце, риторический вопрос в финале абзаца, пауза перед важной информацией в каждой ключевой сцене
Диалоговые: "нам надо поговорить", "обещай что не рассердишься", "это сложно объяснить"
Полный список: 00_CORE/ai_cliches.md
Для каждого запрета — конкретные замены: 00_CORE/anticliche_replacements.md
- Называть эмоцию прямо — только через физику тела и поведение
- Три абзаца подряд начинающихся с одного слова
- Описательные блоки длиннее 4 предложений в середине действия
- Диалог без действия дольше 6 реплик подряд
- Разрешение конфликта через разговор если это не суть сцены

ОБЯЗАТЕЛЬНО:
- Каждая сцена меняет что-то: знание, отношения, ситуацию
- Первое предложение главы — без вводных конструкций, сразу в действие
- Последнее предложение несёт вес — это то что читатель унесёт с собой

═══ СТРУКТУРА (2500-3000 слов) ═══

КРЮК [150-200 слов]:
Начни с действия или детали которая требует продолжения. Без экспозиции.
Читатель должен хотеть знать что дальше — через 50 слов.

РАЗВИТИЕ [900-1200 слов]:
Три такта:
1. Нарастание [300-400 слов] — ситуация усложняется
2. Пик [200-300 слов] — максимальное напряжение или эмоция
3. Спад [300-400 слов] — последствие, новое равновесие или его отсутствие
Каждый абзац имеет функцию. Если убрать — что потеряется?

ФИНАЛ [150-200 слов]:
Либо клиффхэнгер — открытый вопрос или угроза.
Либо тихий удар — деталь или действие которое меняет всё задним числом.
Никогда — резюме того что произошло.
```

## КРИТИЧЕСКИЕ ПОЛЯ

**Три отрывка для голоса** — не заменяй описанием стиля. GPT теряет голос потому что получает инструкцию "пиши атмосферно" вместо конкретного образца ритма. Три отрывка разного типа (экшн / диалог / описание) покрывают все режимы главы.

**Тип главы** — кульминация, поворот, тихая, эмоциональная. GPT автоматически подстраивает темп под тип. Без этого генерирует усреднённое.

**Доминирующее ощущение** — одно слово. "Предательство", "одиночество", "надежда которая рушится". Это якорь для тона всей главы.
