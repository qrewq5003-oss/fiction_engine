**Размер:** ~5KB  
**Зависимости:** META_RULES.yaml, genre_catalog/{genre}.json

---

## 🎯 ЦЕЛЬ

Специфические техники письма для каждого жанра.

---

## 🔍 ДЕТЕКТИВ / НУАР

### СТИЛЬ
- Короткие циничные предложения
- Минимум эмоций, максимум подтекста
- Атмосфера через детали (дождь, сигареты, неон)

### ТЕХНИКИ

**1. ПОСЕВ УЛИК**
```
❌ ПЛОХО (улика из ниоткуда):
В главе 20: Иван вспомнил про пепельницу.
[Читатель: какую пепельницу?]

✅ ПРАВИЛЬНО (посеяна в главе 5):
Глава 5: Пепельница на столе — хрусталь, дорогая.
Глава 20: Иван вспомнил пепельницу. Хрусталь. У жертвы не было денег.
```

**2. RED HERRINGS (ложные следы)**
- Подозрительные персонажи (не убийцы)
- Улики, ведущие не туда
- Мотивы, оказавшиеся не теми

**3. ДЕДУКЦИЯ ЧЕРЕЗ ДИАЛОГ**
```
— Ты был в парке?
— Нет.
— Тогда откуда чернозём под ногтями?
```

**4. АТМОСФЕРА НУАРА**
```
Дождь барабанил по козырьку. Неоновая вывеска мигала — 
«Бар 24», буква «Б» не горела. Иван прикурил. Вторая 
пачка за ночь.
```

## 🐉 ФЭНТЕЗИ

### СТИЛЬ
- Живописность (но без перегруза!)
- Формальность речи (для высокого фэнтези)
- Worldbuilding через действие

### ТЕХНИКИ

**1. МАГИЯ ЧЕРЕЗ ПРАВИЛА**
```
❌ ПЛОХО (магия = deus ex machina):
Иван взмахнул рукой. Враги исчезли. Магия.

✅ ПРАВИЛЬНО (система с ограничениями):
Иван сжал руну. Тепло потекло от ладони к предплечью, 
забирая силы. Защитный щит вспыхнул — минута, не больше. 
Нужно действовать быстро.
```

**2. WORLDBUILDING БЕЗ INFO-DUMP**
```
❌ ПЛОХО:
[300 слов об истории королевства]

✅ ХОРОШО (через действие):
Иван прошёл мимо статуи Первого Короля. Отбитая рука — 
память о восстании 200 лет назад. Никто не чинил. 
Напоминание.
```

**3. АРХАИЧНАЯ РЕЧЬ (с осторожностью!)**
```
❌ ПЛОХО (чрезмерно):
— Милорд, соизволь выслушать сей доклад.

✅ ХОРОШО (умеренно):
— Милорд, — маг склонил голову, — новости с севера.
```

**4. UNIQUE MAGIC SYSTEMS**
- Цена магии (усталость, боль, годы жизни)
- Ограничения (время суток, материалы, знание)
- Последствия (магия меняет мир/персонажа)

## 💕 РОМАНТИКА

### СТИЛЬ
- Эмоциональность, vulnerability
- Сенсорность (touch, proximity)
- Chemistry через напряжение

### ТЕХНИКИ

**1. CHEMISTRY (химия)**
```
Физическая реакция:
Его рука легла на её плечо. Тепло. Она замерла, не дыша.

Dialogue tension:
— Ты не должна была приходить.
— Но я пришла.
Пауза. Слишком долгая.
```

**2. SLOW BURN (медленное развитие)**
```
Глава 1: Первая встреча (искра)
Глава 5: Неловкое сближение
Глава 10: Почти поцелуй (прервано)
Глава 15: Признание
Глава 20: Первый поцелуй
```

**3. INTERNAL CONFLICT**
```
Внешнее: Они идеально подходят друг другу.
Внутреннее: Она боится снова влюбиться. Он скрывает прошлое.
```

**4. VULNERABILITY**
```
❌ ПЛОХО:
— Я люблю тебя.
— Я тоже.

✅ ХОРОШО:
— Я боюсь этого.
— Чего?
— Что ты однажды поймёшь, кто я на самом деле.
```

## 👻 ХОРРОР

### СТИЛЬ
- Атмосферность
- Недосказанность (страшнее то, чего не видно)
- Нарастание напряжения

### ТЕХНИКИ

**1. СОЗДАНИЕ СТРАХА**
```
❌ ПЛОХО (прямо):
Монстр был страшным.

✅ ХОРОШО (через реакцию):
Иван посмотрел. Отвернулся. Желудок сжался. Рвотный рефлекс.
```

**2. FORESHADOWING (предзнаменования)**
```
Глава 1: Лёгкий намёк (странный звук в стене)
Глава 3: Усиление (звук громче, ночью)
Глава 5: Эскалация (царапины на стене)
Глава 7: Выявление (что-то внутри стен)
```

**3. НЕДОСКАЗАННОСТЬ**
```
❌ ПОКАЗАЛИ МОНСТРА ПОЛНОСТЬЮ:
Существо было трёхметровым, с щупальцами и...

✅ ПОКАЗАЛИ ЧАСТИЧНО:
Что-то двигалось в темноте. Слишком много конечностей. 
Иван отвернулся.
```

**4. СЕНСОРНЫЙ УЖАС**
```
Запах: Сладкий, приторный, гнилостный.
Звук: Царапанье. Медленное. Методичное.
Тактильность: Холод от двери. Неправильный холод.
```

## ⚡ ТРИЛЛЕР / ЭКШЕН

### СТИЛЬ
- Темп (быстро!)
- Короткие предложения в экшене
- Ticking clock (ограничение времени)

### ТЕХНИКИ

**1. TICKING CLOCK**
```
Бомба взорвётся через 30 минут.
Поезд уходит в 6:00.
У него осталось 48 часов.
```

**2. ПАРАЛЛЕЛЬНЫЕ ЛИНИИ НАПРЯЖЕНИЯ**
```
Глава чётная (POV героя): Разгадка
Глава нечётная (POV злодея): Подготовка атаки
→ Линии сближаются → Столкновение
```

**3. ИНФОРМАЦИОННЫЙ КОНТРОЛЬ**
```
ВАРИАНТ А (читатель > герой):
Читатель знает, что в подвале бомба. Герой спускается туда.

ВАРИАНТ Б (читатель = герой):
Герой спускается в подвал. Не знает, что там. Читатель тоже.
```

**4. ESCALATION (эскалация)**
```
Глава 1: Угроза по телефону (низкая ставка)
Глава 5: Покушение (средняя)
Глава 10: Похищение близкого (высокая)
Глава 15: Ядерная бомба (критическая)
```

## 🚀 НАУЧНАЯ ФАНТАСТИКА

### СТИЛЬ
- Детальность технологий
- Worldbuilding через термины
- Социальные/философские темы

### ТЕХНИКИ

**1. TECH EXPLANATION БЕЗ INFO-DUMP**
```
❌ ПЛОХО:
[5 абзацев про устройство гипердвигателя]

✅ ХОРОШО:
Гипердвигатель затрещал. Иван ударил по панели. — Работай, 
старая клячЭти прыжки её убивают.
```

**2. ТЕРМИНЫ ЕСТЕСТВЕННО**
```
❌ ПЛОХО:
— Активируй гравитационный стабилизатор третьего поколения.

✅ ХОРОШО:
— Грав-стаб. — Иван ткнул в панель. Гул затих.
```

**3. СОЦИАЛЬНЫЙ КОММЕНТАРИЙ**
```
Не просто "в будущем роботы".
А: "Что значит быть человеком, когда ИИ чувствует?"
```

## 📚 РЕАЛИЗМ / ЛИТЕРАТУРНАЯ ПРОЗА

### СТИЛЬ
- Психологизм
- Метафоричность
- Подтекст на всех уровнях

### ТЕХНИКИ

**1. ВНУТРЕННИЙ МИР**
```
Фокус не на событиях, а на том, как они меняют персонажа.
```

**2. СИМВОЛИЗМ**
```
Дождь = не просто погода, а внутреннее состояние.
Разбитое окно = разрушенные иллюзии.
```

**3. МЕТАФОРИЧЕСКИЙ ЯЗЫК**
```
Их брак давно стал пустой комнатой — стены есть, 
но жить в ней невозможно.
```

## ✅ ЖАНРОВЫЙ ЧЕКЛИСТ

**Для каждого жанра проверь:**

ДЕТЕКТИВ:
- [ ] Улики посеяны заранее
- [ ] Дедукция логична
- [ ] Red herrings present

ФЭНТЕЗИ:
- [ ] Магия имеет правила
- [ ] Worldbuilding через действие
- [ ] Нет info-dump

РОМАНТИКА:
- [ ] Chemistry показана
- [ ] Vulnerability есть
- [ ] Эмоциональные stakes ясны

ХОРРОР:
- [ ] Недосказанность
- [ ] Атмосфера нарастает
- [ ] Страх через реакцию

ТРИЛЛЕР:
- [ ] Ticking clock
- [ ] Эскалация ставок
- [ ] Темп быстрый
