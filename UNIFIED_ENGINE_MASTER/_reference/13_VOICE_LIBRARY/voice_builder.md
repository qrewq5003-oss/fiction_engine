# Инструмент: Создание профиля своего голоса

**Цель:** Зафиксировать голос твоей конкретной серии так чтобы GPT мог его воспроизводить стабильно.

---

## ШАГ 1 — ВЫБЕРИ ЭТАЛОННЫЕ ОТРЫВКИ

Из своего текста (или текста-образца) выбери по одному отрывку каждого типа:

**Отрывок А — экшн/напряжение** (персонаж действует физически):
Выбирай: самую динамичную сцену из написанного. Ту где голос звучит лучше всего.

**Отрывок Б — диалог** (2+ персонажа разговаривают):
Выбирай: диалог с подтекстом или напряжением, не информационный.

**Отрывок В — описание/атмосфера** (место, время, настроение):
Выбирай: сцену где атмосфера важна. Не длиннее 5 предложений.

Каждый отрывок: 3-6 предложений. Не длиннее.

---

## ШАГ 2 — ПОДАЙ В CLAUDE

```
Проанализируй три отрывка и извлеки параметры голоса. Отвечай коротко и конкретно.

ОТРЫВОК А (экшн):
[вставь]

ОТРЫВОК Б (диалог):
[вставь]

ОТРЫВОК В (описание):
[вставь]

Ответь по каждому пункту одним предложением или примером:

1. Средняя длина предложения в каждом режиме (экшн / диалог / описание)
2. Как строится атрибуция диалога (примеры из текста)
3. Как показываются эмоции — через что конкретно
4. Есть ли характерные синтаксические приёмы (что повторяется)
5. Какие слова/конструкции характерны для этого голоса
6. Что в этом тексте никогда не появляется
7. Одно предложение которое лучше всего передаёт голос из каждого отрывка
```

## ШАГ 3 — ЗАПОЛНИ ПРОФИЛЬ

Сохрани в `my_project/voice_profile.md`:

```markdown
# Голос серии: [название]

## Три эталонных предложения
(для вставки в промпт GPT — самые характерные)
1. [из отрывка А]
2. [из отрывка Б]
3. [из отрывка В]

## Параметры
Экшн: предложения [короткие/средние], абзацы [N] предложений
Диалог: атрибуция [минимальная/развёрнутая], действие [часто/редко]
Описание: предложения [средние/длинные], деталей [1-2 / много]
Эмоции: через [физику / действие / иронию / внутренний монолог]
Характерный приём: [если есть]

## Что запрещено в этом голосе
(специфично для этой серии — сверх общего списка ai_cliches.md)
- [запрет 1]
- [запрет 2]

## Контрольные отрывки
(полные — для проверки после генерации)
А: [полный отрывок]
Б: [полный отрывок]
В: [полный отрывок]
```

## ШАГ 4 — ПРОВЕРКА ПОСЛЕ КАЖДЫХ 10 ГЛАВ

```
Сравни голос. Шкала 1-10. Что потеряно.

ЭТАЛОН (контрольный отрывок из профиля):
[вставь отрывок А или Б]

НОВЫЙ ТЕКСТ (аналогичный тип сцены из последней главы):
[вставь]

Ответь: сходство 1-10, что изменилось, что добавить в системный промпт чтобы исправить.
```

Если ниже 7 — обнови поле ГОЛОС в системном промпте.
Добавь конкретный запрет на то что изменилось.
