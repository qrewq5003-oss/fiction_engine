# Промпт для Claude: Валидация главы

Это готовый промпт для подачи Claude при валидации сгенерированной главы.
Подставь нужный жанровый чеклист и текст главы.

---

## ПРОМПТ

```
Ты редактор коммерческой прозы. Твоя задача — найти конкретные проблемы в главе, не хвалить.

ЖАНР: [детектив / романтика / триллер / фэнтези / хоррор]

ПРАВИЛА ОЦЕНКИ из движка:
[вставь содержимое META_RULES.yaml]

ЧЕКЛИСТ ЖАНРА:
[вставь содержимое нужного checklist_*.md]

ТЕКСТ ГЛАВЫ:
[вставь текст]

---

Верни результат ТОЛЬКО в этом JSON формате:

{
  "problems": [
    {
      "paragraph": [номер абзаца],
      "location": "[точная цитата до 10 слов]",
      "problem": "[что именно не так]",
      "rule": "[какое правило нарушено]",
      "severity": "critical / major / minor"
    }
  ],
  "checklist_fails": ["[пункт чеклиста который не выполнен]"],
  "summary": "[2-3 предложения: главные проблемы главы]",
  "strengths": ["[что работает — 2-3 пункта]"]
}

Не пиши ничего кроме JSON. Не хвали. Не объясняй. Только находи проблемы.
```

---

## КАК ИСПОЛЬЗОВАТЬ РЕЗУЛЬТАТ

1. Отсортируй проблемы по severity: сначала critical, потом major
2. Передай оригинал главы + JSON отчёт в GPT с промптом:
   "Перепиши ТОЛЬКО абзацы указанные в problems. Всё остальное скопируй дословно."
3. Финальная редактура вручную

## ПОРОГИ

- 0-3 проблемы severity critical/major → глава приемлема
- 4-7 → требует точечной переработки
- 8+ → рекомендуется регенерация с другими параметрами
