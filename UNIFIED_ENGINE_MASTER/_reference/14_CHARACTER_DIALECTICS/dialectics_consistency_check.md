# Проверка консистентности персонажа

**Проблема:** Персонаж в главе 25 принимает решение которое персонаж из главы 5 не принял бы.
Это либо дуга (изменение показано) либо ошибка (изменение не показано).

---

## ПРОМПТ ДЛЯ ПРОВЕРКИ — подай в Claude

```
Проверь консистентность персонажа. Скажи только если есть проблема — не хвали.

ДИАЛЕКТИКА ПЕРСОНАЖА:
[вставь заполненный шаблон диалектики]

НОВАЯ ГЛАВА:
[вставь текст]

Проверь:
1. Первичная реакция персонажа в сцене — соответствует диалектике?
2. Способ принятия решений — соответствует?
3. Есть ли момент где он делает что-то несовместимое с его границей невозможного?
4. Способ говорить и убеждать — тот же что в профиле?
5. Слепое пятно сыграло роль? Если нет — было ли место где должно было?

Верни только несоответствия. Если всё консистентно — напиши "консистентно" и больше ничего.
```

## МАРКЕРЫ ПОТЕРИ ПЕРСОНАЖА

**Персонаж соглашается слишком быстро** — GPT решает конфликт для удобства сцены.
Проверь: соответствует ли согласие его диалектике убеждения?

**Персонаж знает то что не должен знать** — информационная ошибка.
Проверь memory_graph: мог ли он это знать?

**Персонаж реагирует "правильно" а не "характерно"** — самый частый признак.
Пример: циничный персонаж вдруг проявляет наивную доброту без подготовки.

**Речь персонажа неотличима от другого** — потеря голоса.
Проверь: можно ли угадать кто говорит без атрибуции?
