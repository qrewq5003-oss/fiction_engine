# COMPOSITION GUIDE — РАСШИРЕННЫЙ

**Модуль:** 02_STRUCTURE_ENGINE/composition_guide_extended.md  
**Назначение:** Детальное руководство по композиции истории

---

## 🎯 ТРЁХАКТНАЯ СТРУКТУРА (Базовая)

### ACT 1: SETUP (Завязка) — 25% истории

**Цель:** Познакомить читателя с миром, персонажами, запустить историю

**Ключевые элементы:**

1. **OPENING (Первые 1-3%):**
   - Зацепка читателя
   - Показать обычный мир ГГ
   - Намекнуть на конфликт

2. **INCITING INCIDENT (10-15%):**
   - Событие, которое меняет всё
   - ГГ получает цель/проблему
   - Старый мир разрушен

3. **FIRST PLOT POINT (25%):**
   - ГГ принимает вызов
   - Точка невозврата
   - Переход в акт 2

**Пример (детектив, 200 глав):**
```
Главы 1-50 (25%):
- Гл. 1-5: Обычная жизнь детектива
- Гл. 10: Партнёр убит (INCITING INCIDENT)
- Гл. 25: Детектив клянётся найти убийцу
- Гл. 50: Первая зацепка → начало охоты (PLOT POINT 1)
```

---

### ACT 2: CONFRONTATION (Противостояние) — 50% истории

**Цель:** ГГ пытается решить проблему, терпит неудачи, растёт

**Ключевые элементы:**

1. **RISING ACTION (25-50%):**
   - ГГ активно действует
   - Препятствия растут
   - Малые победы и поражения
   - Введение побочных линий

2. **MIDPOINT (50%):**
   - **КРИТИЧЕСКИ ВАЖЕН**
   - Переломный момент
   - Ставки повышаются
   - Ложная победа ИЛИ ложное поражение
   - ГГ меняет стратегию

3. **COMPLICATIONS (50-75%):**
   - Всё усложняется
   - Противник контратакует
   - Личные жертвы ГГ
   - Конфликт обостряется

4. **SECOND PLOT POINT / DARK MOMENT (75%):**
   - Кажущееся поражение
   - ГГ теряет всё (или думает, что теряет)
   - Самый тёмный час
   - Переход в акт 3

**Пример (детектив, 200 глав):**
```
Главы 51-150 (50%):

Акт 2A (гл. 51-100):
- Гл. 60: Первый подозреваемый (ложный след)
- Гл. 75: Второе убийство (ставки растут)
- Гл. 100: MIDPOINT — ГГ находит имя убийцы!

Акт 2B (гл. 101-150):
- Гл. 110: Убийца знает, что раскрыт
- Гл. 120: Убийца угрожает близким ГГ
- Гл. 130: ГГ почти ловит убийцу, но тот сбегает
- Гл. 150: DARK MOMENT — улики уничтожены, дело закрывают
```

---

### ACT 3: RESOLUTION (Развязка) — 25% истории

**Цель:** Финальное противостояние, разрешение конфликта

**Ключевые элементы:**

1. **RECOVERY (75-85%):**
   - ГГ поднимается после Dark Moment
   - Находит новый план/ресурс
   - Готовится к финалу
   - Собирает союзников

2. **CLIMAX (85-95%):**
   - Финальное столкновение
   - Максимальное напряжение
   - ГГ против антагониста
   - Главный конфликт разрешается

3. **FALLING ACTION (95-98%):**
   - Последствия клаймакса
   - Завязывание побочных линий
   - Эмоциональный момент

4. **RESOLUTION (98-100%):**
   - Новый статус-кво
   - Показать новую жизнь ГГ
   - Намёк на будущее (опционально)

**Пример (детектив, 200 глав):**
```
Главы 151-200 (25%):

Гл. 151-170: RECOVERY
- Гл. 155: ГГ находит новую улику (не уничтоженную)
- Гл. 160: Союзник помогает
- Гл. 170: ГГ готов к финальной операции

Гл. 171-190: CLIMAX
- Гл. 175: Засада на убийцу
- Гл. 180: Погоня
- Гл. 185: Финальная конфронтация
- Гл. 190: Убийца пойман

Гл. 191-195: FALLING ACTION
- Гл. 191: Убийца признаётся
- Гл. 193: Похороны партнёра (эмоции)
- Гл. 195: ГГ получает награду

Гл. 196-200: RESOLUTION
- Гл. 196-200: ГГ берёт отпуск, размышляет о будущем
```

**Ключевые точки:**

- 75%: Plot Point 2 / Dark Moment (кризис)
- 90%: Climax (максимум)
- 100%: Resolution (спад)

## 🎯 MIDPOINT — ДЕТАЛЬНО

### Почему Midpoint критичен:

**1. Делит акт 2 пополам**
   - До: ГГ реагирует на события
   - После: ГГ проактивно действует

**2. Меняет ставки**
   - Информация раскрывается
   - Масштаб проблемы становится больше

**3. Поворот**
   - Ложная победа → оказывается, хуже
   - Ложное поражение → оказывается, есть надежда

**Типы Midpoint:**

**A. ЛОЖНАЯ ПОБЕДА:**
```
ГГ думает: "Я победил!"
На самом деле: "Это только начало"

Пример:
Гл. 100: Детектив находит убийцу!
Гл. 101: Убийца — всего лишь наёмник. Есть заказчик.
```

**B. ЛОЖНОЕ ПОРАЖЕНИЕ:**
```
ГГ думает: "Всё потеряно"
На самом деле: "Это шанс"

Пример:
Гл. 100: Главный подозреваемый убит
Гл. 101: Его смерть раскрывает связь с коррупцией
```

**C. REVELATION:**
```
ГГ узнаёт что-то, что меняет всё

Пример:
Гл. 100: Детектив узнаёт, что убийца — его старый друг
```

## 🔧 SCENE LINKING (Связь сцен)

### Правило: каждая сцена тянет в следующую

**Методы:**

**1. ВОПРОС:**
```
Сцена заканчивается вопросом
"Кто был тот человек в тени?"
→ Читатель хочет узнать → читает дальше
```

**2. ДЕЙСТВИЕ:**
```
Персонаж совершает действие
"Он взял пистолет и вышел из дома"
→ Читатель хочет увидеть, что будет → читает дальше
```

**3. ИНФОРМАЦИЯ:**
```
Сцена раскрывает новую информацию
"Фотография была сделана 10 лет назад"
→ Читатель хочет узнать значение → читает дальше
```

**4. КЛИФФХЭНГЕР:**
```
Сцена обрывается на пике
"Дверь распахнулась. Вошёл..."
→ Читатель хочет узнать, кто → читает дальше
```

**Примеры:**

```
ПЛОХО (нет связи):
Сцена 1: Детектив допрашивает свидетеля. Конец.
Сцена 2: Детектив дома пьёт кофе.
→ Разрыв, нет связи

ХОРОШО (есть связь):
Сцена 1: Свидетель упоминает странного человека. Конец.
Сцена 2: Детектив роется в архивах, ищет этого человека.
→ Действие из сцены 1 тянет в сцену 2
```

## 📋 ЧЕКЛИСТ КОМПОЗИЦИИ

### При планировании истории:

**АКТ 1:**
- [ ] Opening зацепляет за 1-3%
- [ ] Inciting Incident меняет всё (10-15%)
- [ ] Plot Point 1 запускает акт 2 (25%)
- [ ] Представлены ГГ, мир, конфликт

**АКТ 2:**
- [ ] Midpoint в середине (50%)
- [ ] Midpoint меняет ставки или стратегию
- [ ] Rising action (25-50%) с препятствиями
- [ ] Complications (50-75%) усиливают конфликт
- [ ] Dark Moment (75%) — кажущееся поражение

**АКТ 3:**
- [ ] Recovery (75-85%) — ГГ поднимается
- [ ] Climax (85-95%) — максимальное напряжение
- [ ] Falling Action (95-98%) — последствия
- [ ] Resolution (98-100%) — новый статус-кво

**LINKING:**
- [ ] Каждая сцена тянет в следующую
- [ ] Нет "мёртвых" сцен (без последствий)
- [ ] Клиффхэнгеры на концах глав

## 💡 ПРИМЕРЫ

### Пример 1: Детектив (200 глав)

**Акт 1 (1-50):**
- Гл. 1-10: Обычная жизнь, партнёр убит
- Гл. 11-40: Расследование начинается
- Гл. 41-50: ГГ находит первую зацепку → акт 2

**Акт 2 (51-150):**
- Гл. 51-100: Поиски убийцы, ложные следы
- Гл. 100: MIDPOINT — имя убийцы найдено!
- Гл. 101-150: Охота, убийца сопротивляется
- Гл. 150: DARK MOMENT — улики уничтожены

**Акт 3 (151-200):**
- Гл. 151-170: Новая зацепка, подготовка
- Гл. 171-190: Финальная операция, погоня, арест
- Гл. 191-195: Признание убийцы, эмоции
- Гл. 196-200: ГГ двигается дальше

---

### Пример 2: Urban Fantasy (150 глав)

**Акт 1 (1-37):**
- Гл. 1-5: Обычная жизнь мага
- Гл. 10: Демон появляется в городе
- Гл. 20: Маг узнаёт — демон ищет артефакт
- Гл. 37: Маг решает остановить демона

**Акт 2 (38-112):**
- Гл. 38-75: Поиски артефакта, стычки с демоном
- Гл. 75: MIDPOINT — артефакт найден, но проклят!
- Гл. 76-112: Как снять проклятие + защита от демона
- Гл. 112: DARK MOMENT — демон похищает союзника

**Акт 3 (113-150):**
- Гл. 113-127: Маг готовится к последней битве
- Гл. 128-145: Битва с демоном, спасение союзника
- Гл. 146-148: Последствия, город восстанавливается
- Гл. 149-150: Маг принимает новый заказ

## 🔥 КРИТИЧЕСКИЕ ОШИБКИ

### Чего избегать:

**1. ПРОВИСАНИЕ СЕРЕДИНЫ:**
```
❌ Гл. 50-100: Ничего не происходит
✅ Решение: Добавить Midpoint с поворотом
```

**2. СЛАБЫЙ OPENING:**
```
❌ Гл. 1-10: Скучное описание мира
✅ Решение: Начать с действия или интриги
```

**3. ПОЗДНИЙ INCITING INCIDENT:**
```
❌ Гл. 50: Наконец что-то случилось
✅ Решение: Inciting Incident на 10-15%
```

**4. ОТСУТСТВИЕ DARK MOMENT:**
```
❌ ГГ легко побеждает в конце
✅ Решение: Dark Moment на 75%, потом recovery
```

**5. СКОМКАННАЯ РАЗВЯЗКА:**
```
❌ Гл. 199: Клаймакс
    Гл. 200: Всё разрешилось за 1 главу
✅ Решение: Falling Action + Resolution (5-10 глав)
```

## 📝 ИТОГ

Трёхактная структура = **скелет истории**.

Для серий 100+ глав это **необходимый фреймворк**.

Без него — провисание середины, слабые переходы, неудовлетворительный финал.
С ним — tight plotting, правильный пейсинг, satisfying resolution.
