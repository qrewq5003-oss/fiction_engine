## 📝 ПРИМЕРЫ ЗАПОЛНЕННЫХ ШАБЛОНОВ

### Пример 1: Сцена допроса

```yaml
scene_id: "ch127_sc02"
chapter: 127
location: "Допросная комната, участок, поздний вечер"
time: "Через 3 часа после задержания"
pov: "Иван Ковалёв"
purpose: "ГГ выбивает признание, узнаёт место встречи убийцы"
emotional_goal: "Напряжение, психологическое давление"
sensory_hook:
  - "Жёлтый свет лампы режет глаза"
  - "Запах пота и страха в комнате"
conflict: "Свидетель боится убийцу больше полиции"
outcome: "Свидетель называет место встречи убийцы"
anchor: "ГГ звонит: 'Я знаю, где его найти. Едем сейчас.'"
```

### Пример 2: Романтическая сцена

```yaml
scene_id: "ch105_sc01"
chapter: 105
location: "Набережная, закат"
time: "Вечер, после работы"
pov: "Иван Ковалёв"
purpose: "ГГ признаётся Анне, начало романтической линии"
emotional_goal: "Нежность, волнение"
sensory_hook:
  - "Оранжевый свет заката на воде"
  - "Тёплый ветер с запахом моря"
conflict: "ГГ боится испортить дружбу"
outcome: "Анна отвечает взаимностью, отношения меняются"
anchor: "Они целуются. Телефон ГГ звонит — новое дело."
```

### Пример 3: Экшн (погоня)

```yaml
scene_id: "ch185_sc03"
chapter: 185
location: "Городские крыши, ночь, дождь"
time: "Сразу после предыдущей"
pov: "Иван Ковалёв"
purpose: "Погоня за убийцей, почти поймал"
emotional_goal: "Адреналин, разочарование"
sensory_hook:
  - "Дождь хлещет, скользкая черепица"
  - "Стук сердца в ушах"
conflict: "Убийца быстрее, ГГ рискует сорваться"
outcome: "Убийца сбежал, но оставил записную книжку"
anchor: "ГГ открывает книжку — список адресов. Кто эти люди?"
```

## 🎯 ФОРМУЛА: ЦЕЛЬ → КОНФЛИКТ → ИЗМЕНЕНИЕ

1. **ЦЕЛЬ:** Что персонаж хочет в сцене
2. **КОНФЛИКТ:** Что мешает
3. **ИЗМЕНЕНИЕ:** Что изменилось к концу
