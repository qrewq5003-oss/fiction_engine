# Проверка контракта — промпт

Используй после написания финала арки или серии.

---

## ПРОМПТ — подай в Claude

```
Проверь выполнение читательского контракта жанра.

ЖАНР: [эпическое / городское / тёмное фэнтези]

КОНТРАКТ ЖАНРА:
[вставь нужный раздел из fantasy_contracts.md]

КРАТКОЕ СОДЕРЖАНИЕ АРКИ/СЕРИИ:
[3-7 предложений что произошло]

ФИНАЛ:
[вставь финальную главу или её краткое описание]

Проверь:
1. Каждый пункт из "Обязательно" — выполнен или нет?
2. Есть ли нарушения из списка "Нарушение контракта"?
3. Если нарушение есть — была ли к нему подготовка в тексте? (осознанное нарушение)
4. Что читатель получил из раздела "Желательно"?

Верни только проблемы. Если контракт выполнен — напиши "контракт выполнен".
```
