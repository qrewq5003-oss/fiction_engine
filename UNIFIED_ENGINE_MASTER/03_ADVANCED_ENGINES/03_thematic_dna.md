## 🎯 НАЗНАЧЕНИЕ

Система проникновения темы на ВСЕ уровни текста: диалоги, описания, выборы персонажей, символы, арки, даже погоду.

**Тема не просто "есть в списке" — она живёт в каждой сцене.**

---

## 📊 ТЕМАТИЧЕСКИЕ СЛОИ

### 1. ЯВНЫЙ СЛОЙ (Explicit)
Тема названа прямо в диалогах/мыслях.

**Пример (тема "цена прошлого"):**
```
ДИАЛОГ:
— Ты не можешь убежать от прошлого, Иван.
— Могу. Просто плачу за это каждый день.
```

**Когда использовать:** 20% времени (не переборщить)

---

### 2. ПОДТЕКСТ (Subtext)
Тема не названа, но очевидна из действий.

**Пример:**
```
Иван смотрит на фото пятилетней давности. Трое мёртвых. Он сжимает фото, 
но не выбрасывает. Никогда не выбрасывает.
```

**Когда использовать:** 50% времени (основной метод)

---

### 3. СИМВОЛИЧЕСКИЙ (Symbolic)
Тема через образы и метафоры.

**Пример:**
```
Старый квартал не меняется. Те же дома, те же улицы. Только пепел на стенах — 
память о пожаре. Иван проходит мимо, не поднимая глаз.
```

**Символ:** Пепел = прошлое, которое не стирается

**Когда использовать:** 30% времени (атмосферные сцены)

## 🎨 ТЕМАТИЧЕСКИЕ ИНСТРУМЕНТЫ

### 1. ТЕМА В ДИАЛОГАХ

**Плохо (on-the-nose):**
```
— Главная проблема нашего общества — неравенство!
— Да, классовая борьба разрушает нас!
```

**Хорошо (через конфликт):**
```
— Тебе легко говорить. У тебя всегда были деньги.
— А у тебя всегда были оправдания.
```

---

### 2. ТЕМА В ОПИСАНИЯХ

**Тема: Изоляция**

**Плохо:**
```
Он был одинок.
```

**Хорошо:**
```
Квартира Ивана выходила окнами во двор-колодец. Соседи не здоровались. 
Телефон не звонил уже неделю.
```

---

### 3. ТЕМА В ДЕЙСТВИЯХ ПЕРСОНАЖЕЙ

**Тема: Искупление**

```
Ch5: Иван спасает незнакомца (хотя рискует)
Ch9: Иван отдаёт единственную улику Марии (хотя нужна ему)
Ch15: Иван жертвует собой в финале (искупление завершено)
```

Каждое действие = шаг по тематической арке

---

### 4. ТЕМА В АРКАХ ПЕРСОНАЖЕЙ

**Тема: Доверие vs Предательство**

```
АРК ИВАНА:
Start: Не доверяет никому (травма прошлого)
  ↓
Ch5: Вынужден довериться Марии (малый шаг)
  ↓
Ch10: Предан информатором (откат назад)
  ↓
Ch15: Доверяет Марии полностью (финал арки)
  ↓
End: Научился доверять снова, но избирательно
```

---

### 5. ТЕМА В SUBPLOT'АХ

**Главная тема: Цена прошлого**

**Subplot 1 (Романтика Иван-Мария):**
- Прошлое разделило их → воссоединение = преодоление прошлого

**Subplot 2 (Культ):**
- Культ пытается воскресить прошлое (Древних) → прямая параллель главной теме

**Subplot 3 (Иван и отец):**
- Иван не простил отца → до смерти отца → цена прошлого личная

## 📈 ТЕМАТИЧЕСКАЯ ПЛОТНОСТЬ

**Формула:**
```
Тематическая плотность = 
  (Главы с тематическими элементами) / (Всего глав) × 100%

Оптимум: 70-85%
Проблема: <50% = тема размыта
Проблема: >90% = тема навязчива
```

**Проверка:**
```
Ch1: Тема упомянута? ✓ (через символ пепла)
Ch2: Тема упомянута? ✓ (прошлое Ивана в диалоге)
Ch3: Тема упомянута? ✗ (чистый экшен)
Ch4: Тема упомянута? ✓ (Иван вспоминает то дело)
...

Плотность: 18/24 глав = 75% ✓ Хорошо
```

## 💡 ЗОЛОТЫЕ ПРАВИЛА

1. **Показывай, не говори:** Подтекст > прямое называние (50% vs 20%)
2. **Тема = конфликт:** Каждый выбор персонажа = тематический выбор
3. **Символы последовательны:** Если пепел = прошлое, используй до конца
4. **Subplot'ы = зеркала:** Отражают главную тему с других сторон
5. **Плотность 70-85%:** Не каждая глава, но большинство
6. **Арка темы:** Тема развивается, не просто повторяется

## ## MINI (QUICK режим — суть за 10 строк)

**Тема не в списке — она в каждой сцене.** Диалоги, описания, выборы, символы — всё несёт тему.

**Три уровня темы в сцене:**
1. **В диалоге:** персонажи говорят о конкретном — но их конфликт отражает тему.
   Тема "неравенство": "Тебе легко говорить. У тебя всегда были деньги." — не "давайте обсудим классовую борьбу".
2. **В описании:** деталь среды отражает тему. Тема "изоляция" → двор-колодец, не здоровающиеся соседи, неделю молчащий телефон.
3. **В выборе персонажа:** дилемма сцены — это тема в действии.

**Запрещено:** персонаж произносит тему вслух ("главная проблема нашего общества...").
**Правило на главу:** одна деталь описания и один момент диалога которые отражают тему — без объяснений.
**Тест:** убери все прямые упоминания темы. Она всё ещё чувствуется? Если да — сделано правильно.
