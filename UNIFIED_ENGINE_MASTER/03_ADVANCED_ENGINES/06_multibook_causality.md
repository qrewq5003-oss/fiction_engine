## 🎯 НАЗНАЧЕНИЕ

Управление причинностью через серию книг. Отслеживает setups/payoffs через несколько книг.

---

## 📊 СТРУКТУРА

### CAUSALITY CHAIN (Цепь причинности)

```
КНИГА 1, Ch3: Иван находит странный артефакт (SETUP)
  ↓
КНИГА 1, финал: Артефакт не используется (hanging thread)
  ↓
КНИГА 2, Ch7: Артефакт начинает светиться (REMINDER)
  ↓
КНИГА 3, Ch15: Артефакт = ключ к запечатыванию Древних (PAYOFF)
```

**Правило:** Setup в книге N → Payoff не позже книги N+2

**Арка через серию:**
```

  ↓
КНИГА 2: Иван учится доверять Марии
  ↓
```

## ✅ СЕРИЙНЫЙ ЧЕКЛИСТ

```
[ ] Каждый setup имеет payoff (записан в tracker)
[ ] Не >5 незакрытых setups одновременно
[ ] Долгосрочные арки персонажей прогрессируют каждую книгу
[ ] Мир эволюционирует (не статичен)
[ ] Отсылки к прошлым книгам естественны
```

---

## 💡 ЗОЛОТЫЕ ПРАВИЛА

1. **Чеховское ружьё на уровне серии:** Если упомянул → используй
2. **Payoff не позже 2 книг:** Иначе читатели забудут
3. **Каждая книга = standalone + вклад в серию:** 70/30
4. **Арки персонажей = марафон:** Малые шаги каждую книгу

## ## MINI (QUICK режим — суть за 10 строк)

**Серия = один setup в книге 1 — payoff в книге 3.** GPT не отслеживает через тома. Ты должен.

**Три правила серийной причинности:**
1. **Каждый setup записан:** если в книге 1 посадил семя — оно должно прорасти. Ружьё Чехова через тома.
2. **Мир эволюционирует:** события книги 1 изменили мир — книга 2 живёт в изменённом мире, а не делает вид что ничего не было.
3. **Персонажи несут прошлое:** они помнят что происходило. Их решения учитывают опыт предыдущих книг.

**Серийный чеклист для текущей главы:**
- Есть ли здесь payoff для setup из предыдущей книги?
- Есть ли новый setup который выстрелит позже?
- Не больше 5 открытых незакрытых arcs одновременно?

**Красный флаг:** персонаж в книге 3 делает то что прямо противоречит его опыту из книги 1 — без объяснения.
