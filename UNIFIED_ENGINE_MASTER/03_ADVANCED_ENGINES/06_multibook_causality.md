**Серия держит причинность через тома:** что посеяно в первой книге, прорастает в третьей.

**Три правила:**
1. **Посеянное прорастает.** Ружьё Чехова работает и через книги: упомянутое важное должно выстрелить не позже чем через две книги, иначе его забудут.
2. **Мир меняется.** События прошлых книг изменили мир — новая книга живёт в изменённом мире, а не делает вид, что ничего не было.
3. **Персонажи помнят.** Их решения учитывают опыт прошлых книг.

**Для текущей главы:** есть ли здесь расплата за посеянное раньше? Есть ли новый посев, который выстрелит позже? Открытых незакрытых линий одновременно — не больше пяти.

**Красный флаг:** персонаж делает то, что прямо противоречит его опыту из прошлых книг, — без объяснения.

## PROMPT:FULL

**Цепь через тома:** посев → в финале книги не использован (открытая нить) → напоминание в следующей книге → расплата. Напоминание держит нить живой.

**Арки персонажей — марафон:** в каждой книге малый шаг, а не весь путь сразу. От недоверия — к доверию одному человеку — к доверию команде — к лидерству.

**Каждая книга — самостоятельная история и вклад в серию.** Примерно 70 на 30: книга закрывает свой главный конфликт, но продвигает большие линии.

**Отсылки к прошлым книгам** — естественные, через то, что персонаж помнит и что изменилось вокруг, а не пересказом для тех, кто не читал.

## 📊 СТРУКТУРА

### CAUSALITY CHAIN (Цепь причинности)

```
КНИГА 1, Ch3: Иван находит странный артефакт (SETUP)
  ↓
КНИГА 1, финал: Артефакт не используется (hanging thread)
  ↓
КНИГА 2, Ch7: Артефакт начинает светиться (REMINDER)
  ↓
КНИГА 3, Ch15: Артефакт = ключ к запечатыванию Древних (PAYOFF)
```

**Правило:** Setup в книге N → Payoff не позже книги N+2

## ✅ СЕРИЙНЫЙ ЧЕКЛИСТ

```
[ ] Каждый setup имеет payoff (записан в tracker)
[ ] Не >5 незакрытых setups одновременно
[ ] Долгосрочные арки персонажей прогрессируют каждую книгу
[ ] Мир эволюционирует (не статичен)
[ ] Отсылки к прошлым книгам естественны
```

## 💡 ЗОЛОТЫЕ ПРАВИЛА

1. **Чеховское ружьё на уровне серии:** Если упомянул → используй
2. **Payoff не позже 2 книг:** Иначе читатели забудут
3. **Каждая книга = standalone + вклад в серию:** 70/30
4. **Арки персонажей = марафон:** Малые шаги каждую книгу
