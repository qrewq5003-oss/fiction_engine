## 🎨 10 VOICE PARAMETERS

### 1. FORMALITY [1-5]
```
1-CASUAL | 2-RELAXED | 3-NEUTRAL | 4-FORMAL | 5-ELEVATED
```

### 2. METAPHOR DENSITY [0-10 per 1k words]
```
0     — нет метафор: клинический, документальный, жёсткий триллер
1-2   — минимум: реализм, процедурал, ранний Хемингуэй
3-5   — стандарт: большинство коммерческой прозы, детектив, YA
6-8   — насыщенный: литературная проза, романтика, городское фэнтези
9-10  — поэтический: магический реализм, высокий эпик, лирическая проза
```
**Правило:** метафора работает если неожиданна и точна одновременно. Больше 8/1000 — риск "красивость ради красивости".

### 3. SENTENCE RHYTHM [avg words]
```
5-10 STACCATO | 12-18 STANDARD | 20-30 FLOWING | 30+ LITERARY
```

### 4. VOCABULARY [1-5]
```
1-SIMPLE | 2-ACCESSIBLE | 3-STANDARD | 4-ADVANCED | 5-ELITE
```

### 5. TONAL COLOR
```
NOIR | WHIMSICAL | CLINICAL | LYRICAL | GRITTY | PHILOSOPHICAL
```

### 6-10. HUMOR, DETAIL, TEMP, TIME, STANCE

## ## MINI (QUICK режим — суть за 10 строк)

**Голос = 10 параметров которые держишь константными.** Меняется мир, характеры, сюжет — голос остаётся.

**10 параметров — быстрая шкала:**
1. Формальность: [1=разговорный ↔ 5=литературный]
2. Метафоры: [0=нет ↔ 10=много / 1000 слов]
3. Ритм предложений: [5-10=рубленый / 12-18=стандарт / 20+=текучий]
4. Словарь: [1=простой ↔ 5=элитарный]
5. Тональный цвет: [нуар / лиричный / циничный / клинический / философский]
6. Юмор: [0=нет / 1=редко / 2=умеренно / 3=часто]
7. Детализация: [1=минимум ↔ 5=максимум]
8. Время: [прошедшее / настоящее]
9. Дистанция: [близкая / средняя / отстранённая]
10. Позиция нарратора: [сочувствующий / нейтральный / ироничный]

**Жанровые пресеты:**
Нуар: формальность 2, метафоры 3, ритм 8-12, нуар цвет, юмор 1 (чёрный).
Хоррор: формальность 3, метафоры 4, ритм 10-15, дистанция средняя→близкая в пиках.
Романтика: формальность 2-3, метафоры 5, ритм 15-20, лиричный, дистанция близкая.

**Правило:** пропиши параметры серии один раз. Сверяйся при каждом подозрении что голос ушёл.
