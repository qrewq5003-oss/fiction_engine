ROADMAP_TEXT.md, «Отложено: проверка второй линии»).

- `rewrite.py [каталог]` — каждую главу «детектив + романтика» из
  `bench/ab-judge-secondary-2026-10-05.json` GLM переписывает дважды:

  два судьи; печатает, различают ли они A и B. Пишет `questions.json`.

Для другого семейства жанров: свои главы-основа в `rewrite.py` (поле
`chs`), свои задания A/B (`TASK`) и свои вопросы (`Q` в `questions.py`).
